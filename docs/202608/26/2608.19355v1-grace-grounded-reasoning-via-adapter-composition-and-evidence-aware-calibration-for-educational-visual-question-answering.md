## 摘要
教育视觉问答（VQA）要求模型利用语言和视觉证据解决面向课程的多项选择题。与传统的开放式VQA相比，教育示例通常包含结构化的评估元数据、图表或图像背景，以及语义上相近的答案选项，这为问题-选项捷径创造了很大的机会。我们在此环境下开发和评估了一种面向冻结的多模态大语言模型的参数高效适配框架。我们介绍了GRACE，即通过适配器组合与证据感知校准实现的有依据推理，该框架利用每个问题的教学状态来专门化轻量级语言和视觉适配。该状态结合了推理可见的科目、分组技能、年级、视觉背景、问题意图和选项结构线索。GRACE使用针对特定因素的提示和轻量级视觉适配器，然后在共享的多模态背景下应用证据感知选项校准对所有候选者进行评分。在ScienceQA上，GRACE将共享适配器基线的整体准确率从90.5%提升到93.1%，在图像背景问题上从88.7%提升到91.2%。移除教学组合、选项校准或视觉适配器分别使整体准确率降低1.4、1.0和1.5个百分点。这些受控结果表明，结构化的教育状态是参数高效多模态适配的有效路由信号。

## Abstract
Educational visual question answering, or VQA, requires models to solve curriculum-oriented multiple-choice questions using both language and visual evidence. Compared with conventional open-ended VQA, educational examples often include structured assessment metadata, diagrams or image contexts, and semantically close answer options, creating strong opportunities for question-option shortcuts. We develop and evaluate a parameter-efficient adaptation framework for a frozen multimodal large language model in this setting. We introduce GRACE, Grounded Reasoning via Adapter Composition and Evidence-Aware Calibration, a framework that uses the pedagogical state of each question to specialize lightweight language and vision adaptation. The state combines inference-visible subject, grouped skill, grade, visual-context, question-intent, and option-structure cues. GRACE uses factor-specific prompts and lightweight visual adapters, then applies evidence-aware option calibration to score all candidates under a shared multimodal context. On ScienceQA, GRACE improves a shared-adapter baseline from 90.5 percent to 93.1 percent overall accuracy and from 88.7 percent to 91.2 percent on image-context questions. Removing pedagogical composition, option calibration, or the visual adapter reduces overall accuracy by 1.4, 1.0, and 1.5 points, respectively. These controlled results show that structured educational state is an effective routing signal for parameter-efficient multimodal adaptation.

### 1. 核心问题与研究动机

- **研究背景**：教育视觉问答（Educational VQA）要求模型结合语言与视觉证据，解答面向课程的多项选择题（如 ScienceQA 基准）。与开放式 VQA 不同，教育题型通常附带结构化评估元数据（学科、年级、技能标签）、图表或图像背景，以及语义上高度相近的干扰选项，给模型提供了大量“问题–选项”统计捷径，可能使其不依赖图像即可作答。
- **核心问题**：
  1. **如何利用教育数据中推断可见的结构化信息**（教学状态）来指导参数高效适配，而不是对所有样例使用统一的共享适配器；
  2. **如何缓解语言捷径学习**，使模型真正依赖视觉证据，而不是仅凭文本统计作答；
  3. **如何避免对大模型进行昂贵且不必要的全量微调**。
- **总体意义**：论文提出结构化教学状态可作为参数高效多模态适配的有效路由信号，在冻结大模型主干的前提下显著提升教育 VQA 的准确率与视觉依赖度。

### 2. 方法论：核心思想与关键技术

- **总体框架**：GRACE = 基于适配器组合与证据感知校准的有依据推理框架。以 **Qwen2.5-VL-7B-Instruct** 为骨干，冻结视觉 Transformer 块和语言解码器，仅训练“视觉–语言”多模态连接器与轻量适配模块（共约 49.3M 可训练参数，约占 7B 参数的 0.7%）。
- **教学状态（Pedagogical State）**：
  - 每个样本构造状态向量 \(z_i = \{s_i, t_i, c_i, g_i, u_i, v_i\}\)，分别表示：学科/主题、分组技能类别、视觉上下文、年级、问题意图类别、选项结构描述。
  - 其中学科、技能、视觉上下文、年级来自 benchmark 元数据；问题意图与选项结构从推理可见的题干和选项中计算得出。
  - 明确禁止使用正确答案、题解、讲义、解释等任何“事后标注”信息。
- **教学感知的适配器组合（Pedagogy-Aware Adapter Composition）**：
  - 构造因式化提示词库 \(P = \{P_0, P_s, P_t, P_c, P_g, P_{qi}, P_{os}\}\)，最终实现含 **93 个提示组件**，每组件前缀长度 \(l=10\)。
  - 组合前缀公式：\(P(z_i) = P_0 + \alpha_s P_s^{s_i} + \alpha_t P_t^{t_i} + \alpha_c P_c^{c_i} + \alpha_g P_g^{g_i} + \alpha_{qi} P_{qi}^{u_i} + \alpha_{os} P_{os}^{v_i}\)。
  - 系数 \(\alpha\) 由一个小型门控网络基于元数据类别和题干/选项描述嵌入生成；缺失字段使用显式未知类别嵌入。
  - **关键优势**：因式化提示库的规模随因素类别数线性增长（\(1+\sum n_f\)），而联合专家方案随组合数乘积（\(\prod n_f\)）增长，更适配教育数据中联合组合稀疏的特点。
- **状态条件视觉适配（State-Conditioned Visual Adaptation）**：
  - 在视觉 Transformer 第 4 和第 8 层插入两层瓶颈适配器，瓶颈维度 256。
  - 更新公式：\(\tilde{h}_i^{(\ell)} = h_i^{(\ell)} + a_i^{(\ell)} A_\ell(h_i^{(\ell)})\)，其中门控系数 \(a_i^{(\ell)} = G_\ell(z_i) \in [0,1]\) 同样基于教学状态生成，实现语言与视觉路径共享同一教育描述的协同调节。
- **证据感知选项校准（Evidence-Aware Option Calibration / OCAV）**：
  - 针对自由生成与有限候选集不匹配的问题，直接对所有候选选项在共享多模态上下文下评分。
  - 长度归一化条件对数似然：\(\ell_{ij} = \frac{1}{|o_{ij}|}\sum_{t=1}^{|o_{ij}|} \log p(o_{ij,t} | I_i, q_i, O_i, z_i, o_{ij,<t})\)，消除选项长短的机械性优势。
  - 轻量验证器 \(V_\eta\) 联合评估候选选项与图像、题干、教学状态。
  - 最终得分：\(S_{ij} = \lambda \ell_{ij} + \gamma V_\eta(I_i, q_i, o_{ij}, z_i)\)，取 \(\lambda=1, \gamma=1\)。
  - 列表式训练损失：\(L_{ocav} = -\log \frac{\exp(S_{iy_i})}{\sum_{j=1}^K \exp(S_{ij})}\)，训练正确选项在同类所有干扰项中排在首位。
- **完整训练目标**：\(L = L_{ans} + \lambda_o L_{ocav}\)，其中 \(L_{ans}\) 为答案生成损失，\(\lambda_o = 1.0\)。
- **视觉依赖评估**：采用匹配的图像移除干预——将原始图像替换为同尺寸全灰图像，经完全相同模型与预处理流程，对比两种条件下的准确率差异。

- **受控基线**：
  - 冻结骨干（frozen backbone）；
  - LoRA（低秩适配）；
  - 共享适配器（Shared adapter）：单一路径的 Houlsby 风格适配器，无教学组合。

  - **GRACE：93.1%**（较冻结 +5.6，较共享适配器 +2.6；IMG 上较冻结 +6.3、较共享适配器 +2.5）。

### 4. 分类结果与关键发现

- **按科学学科划分（受控对比）**：

  - 社会科学（SOC）：GRACE 95.5%，优于共享适配器 93.1%；
  - 语言科学（LAN）：GRACE 92.6%，优于共享适配器 90.5%；
  - 可以看出，视觉依赖最强的自然科学类别收益最大，直接印证了“教学状态路由 + 视觉适配”对提升真正多模态推理的关键作用。
- **按图像上下文划分**：

- **按年级与难度划分**：

  - 含干扰选项型题目（MIS）上的提升尤为突出，说明 OCAV 校准对排除高相似度语义干扰选项具有直接帮助。
- **与参考方法对比（跨骨干、仅供任务背景参考）**：
  - GRACE 在相同骨干下刷新 ScienceQA 测试集最佳结果，较此前端到端多模态最优的 Multimodal-CoT Large（92.55%）高约 0.6 个百分点，且可训练参数仅为其一个数量级以下，说明参数效率与性能可以兼顾。

### 5. 深入分析与讨论

- **教学状态因素贡献排序**：在提示组合消融中，移除“问题意图类别（question intent）”的下降幅度最大（约 −0.8），其次为“选项结构描述”（约 −0.5）与“视觉上下文”（约 −0.4）；年级与技能类别贡献相对较小但持续为正。这一排序说明，由推理可见文本推断出的元信息比静态元数据更能激励模型进行审慎推理。
- **组合式路由 vs. 统一路由**：将因式化提示库替换为等参数量共享前缀（无状态条件）后准确率降低至 91.6%，验证了门控组合并非简单增加参数，而是通过教学状态实现了按样本软路由的增益。
- **门控系数可解释性**：GNN 门控对不同学科样本生成了显著不同的可视化模式（示例中物理题在“科学因素”上分配了更高权重、文学题在“语言科学/技能因素”上权重更高），说明模型自动学习了与人类直觉一致的教学素材路由。
- **视觉依赖与校准的耦合**：移除 OCAV 且只保留生成损失时，GRACE 的“全图 vs 空白图”差距缩小到 9.1；加入 OCAV 后差距上升至 12.8，同时总体准确率上升。这表明 OCAV 不仅提升排序能力，还通过显式要求“在图像存在时解释正确选项”强化了视觉锚定，抑制了纯文本捷径。
- **参数效率**：训练参数量对比为 LoRA 约 64M、共享适配器约 48M、GRACE 约 49.3M，GRACE 在仅比共享适配器多 1.3M 参数的情况下达成 2.6 个百分点的提升，且仅为 7B 骨干的 0.7%。
- **局限性与失败案例分析**：
  1. **高度专业化的视觉推理失败**：涉及仪器读数换算（如量筒精确读数）、地图比例尺估算等任务，即使 GRACE 正确路由到科学上下文，冻结的视觉编码依然无法精确完成数值型空间计量；
  2. **元数据缺失的领域迁移**：当评测数据完全没有教学状态标注时，需先用轻量分类器推断状态，推断误差会向下游传递，性能下降约 2–3%；
  3. **上下文长度扩展不足**：OCAV 需要同时编码题目、图像与全部选项，当选项超过 5 个或题目文本过长时，显存占用与延迟显著上升，限制了在超长文档级教育评测上的直接应用。

### 6. 结论与贡献总结

- GRACE 首次将“教学状态”（pedagogical state）这一结构化教育信息引入参数高效多模态适配：它同时作为提示组合的软路由信号、视觉适配器的门控条件和选项校准的辅助上下文，在冻结 7B 级视觉语言模型的前提下实现了 ScienceQA 最优准确率（93.1%）。
- 通过三项核心组件（教学感知适配器组合、状态条件视觉适配、证据感知选项校准）的协同，GRACE 同时实现了**高参数效率**（仅 0.7% 可训练参数）与**更强的视觉依赖**（全图与空白图准确率差距从 7.8 拉大至 12.8），有效缓解了教育 VQA 的语言捷径问题。
- 消融与案例分析表明，组合式教学状态路由比统一共享前缀更高效，且模型学到的门控权重与教育工作者直觉一致；该机制为多模态大模型在课程化教育场景的低成本定制提供了新范式。

### 7. 论文价值与可改进方向

- **学术贡献**：为“结构化任务描述驱动的参数高效微调”提供了干净、可复现的实证：结构化状态不必引入新的专家模块，而是通过轻量门控对共享提示库与共享适配器做软组合。
- **实践意义**：冻结大模型主干有效降低了部署门槛，学校或教育平台可在消费级 GPU 上按学科、年级、题型动态路由到适应性行为，无需为每门课程重新微调。
- **可改进方向**：
  1. 将教学状态从离散标签扩展为自由文本/描述句子，以覆盖开放领域课程问答；
  2. 引入连续视觉证据定位（如区域级注意力）以增强数值型读数能力；
  3. 设计端到端状态推断模块与适配器联合训练，缓解对 benchmark 元数据标注的依赖；
  4. 推广到更多教育评测集（如 TQA、MMMU-Pro 教育子集）验证跨数据集泛化性。
