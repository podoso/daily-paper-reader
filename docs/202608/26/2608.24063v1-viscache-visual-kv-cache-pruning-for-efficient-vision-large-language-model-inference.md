## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理方面取得了显著成功，但其长上下文推理仍然因视觉键值（KV）缓存的巨大计算和内存开销而代价高昂。现有的KV压缩方法通常对视觉token和层进行均匀剪枝，导致大量信息丢失和性能下降。为解决这一挑战，我们提出了VisCache，一种即插即用的无训练粗到细视觉KV缓存剪枝框架，由两个协同阶段组成。首先，一个轻量级VLM通过选择性转发语义上有信息量的关键帧来过滤时间冗余。其次，我们引入了PruneKV，一种针对VLLMs注意力动态量身定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线式逐层预算分配以及不对称更新机制，选择性剪枝键同时融合值，从而保留关键的上下文信息。大量实验表明，VisCache显著提高了推理效率，实现了高达2.35倍的加速和显著的内存减少，同时仅需保留19-28%的KV缓存即可保持竞争力的性能。VisCache持续优于现有基线，为长上下文VLLM推理建立了效率与性能之间新的帕累托前沿。代码可在https://github.com/Wlklk/VisCache获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

## 1. 核心问题与研究动机

- **背景**：视觉大语言模型（VLLMs）在多模态推理任务中表现卓越，但其长上下文推理面临严重瓶颈。长视频输入产生海量视觉 token，导致视觉 Key-Value（KV）缓存急剧膨胀，造成两大问题：
  - **内存瓶颈**：KV 缓存主导 GPU 显存消耗，加剧显存带宽争用，严重制约吞吐量。
  - **计算瓶颈**：注意力计算随序列长度二次增长，放大延迟开销。
- **现有方法的不足**：已有 KV 压缩方法（如均匀剪枝、量化、低秩分解）通常对视觉 token 和层做**统一/粗粒度处理**，忽视了两个关键结构特性：
  - 不同 transformer 层对视觉信息的依赖程度不同（浅层保留细节，深层偏语义）；
  - 注意力机制中 **key 与 value 功能不对称**（key 决定相关性选择，value 承载实际内容）。

## 2. 方法论：VisCache 两阶段框架

### 2.1 核心思想
VisCache 通过**粗到细**的双阶段范式压缩视觉 KV 缓存，无需训练、即插即用：

- **Stage 1（输入级粗过滤）**：在信息进入 VLLM 之前，用轻量 VLM 过滤时间冗余；
- **Stage 2（模型级细压缩）**：在推理过程中，用 PruneKV 对 KV 缓存做层感知的外科手术式压缩。

### 2.2 Stage 1：Prompt-Aware Scout 时间冗余过滤
- 使用轻量视觉-语言模型（如 **CLIP**）作为 scout，提取 prompt 和视频帧的跨模态表征。
- 采用 **Maximal Marginal Relevance（MMR）** 准则平衡相关性与多样性：

$$\text{MMR}(f) = \lambda \cdot \text{sim}(h_f, h_t) - (1-\lambda) \cdot \max_{f' \in \Omega} \text{sim}(h_f, h_{f'})$$

- 迭代选择 MMR 分数最高的帧，直至达到目标帧保留比例 $p$，从而获得紧凑、查询相关、冗余最小的关键帧集合。

### 2.3 Stage 2：PruneKV 层感知 KV 压缩
包含三个核心组件：

**（1）Token 重要性评分**：在预填充阶段，聚合所有层的注意力权重作为 token 重要性信号：

$$s_v = \frac{1}{L}\sum_{l=1}^{L}\sum_{i=1}^{N} A^l_{i,v}$$

**（2）抛物线式层级预算分配**：设截断层阈值 $h$（论文默认 $h = \frac{3}{4}L$），对 $l \in [1, h]$ 的层按抛物线衰减分配预算：

$$b_l = 1 - \frac{(l-1)^2}{2(h-1)^2}$$

该曲线浅层保留更多 token，深层压缩更激进，并通过归一化满足全局保留约束。

**（3）非对称键值更新（剪键融值）**：利用 key/value 的功能不对称性——丢弃不重要的 **key**，但将对应的 **value** 通过相似度加权融合到保留 token 中。具体实现包括重分配矩阵 $\Phi$（softmax 归一化的值相似度）和融合公式：

$$V^{\text{new}}_k = \mu V_k + (1-\mu)(\Phi V_d)$$

其中 $\mu = 0.7$ 平衡原始信息与融合信息。

## 6. 主要结论与发现

1. **效率显著提升**：仅保留 **19-28%** 的 KV 缓存，即可实现最高 **2.35×** 推理加速，FLOPs 降至全缓存的 6-15%。
2. **性能不降反升**：VisCache 在 28% RR 下平均准确率（3B：45.64%，32B：56.86%）**超过全缓存基线**（44.16%、57.46% 中 32B 稍低但接近），大幅超越同 RR 下的所有基线。
3. **抛物线预算优于算术/几何递进**：在激进压缩下优势尤为明显，几何递进（PDrop）因浅层过度压缩而显著退化。
4. **值融合有效**：除几何预算外，融合机制一致带来准确率提升，验证了键值不对称设计的合理性。
5. **两阶段互补**：单独使用 Scout 在部分任务上会丢失必要上下文，单独使用 PruneKV 效果稳定但不及联合；组合后在各 RR 下均最优。
6. **全局共享 token 排名优于分层独立排名**：聚合各层注意力提供更稳健的重要性估计。
7. **模型规模扩大时优势增大**：32B 模型上 VisCache（28%）超越所有基线（40%）的性能。

## 7. 方法亮点

- **免训练即插即用**：无需任何微调，可便捷接入现有 VLLM，实用价值高。
- **粗到细双层冗余消除**：在输入层（帧级）和推理层（token 级）同时消除冗余，逻辑层次清晰。
- **抛物线预算设计新颖**：以 "浅层保细节、深层弃抽象" 为依据的分配策略，思路直观且实证最优。
- **键值不对称压缩**：剪键保留相关性选择、融值保留信息内容——对注意力机制功能结构的精确建模。
- **MMR 关键帧筛选**：兼顾查询相关性与帧多样性，且通过 Jaccard 相似度验证了 scout 所选帧与 VLLM 高注意力区域的**一致性**（0.70-0.85）。
- **兼容性强**：与 KV 量化（KIVI/FlatQuant）、现有 token 剪枝方法可叠加使用，正交性好。

## 8. 不足与局限

### 8.1 方法本身的局限（作者自述）
- **Scout 对齐问题**：CLIP 等轻量 VLM 的视觉表征可能与主 LLM 骨干不完全对齐，导致所选关键帧偏离主模型的"最优"选择；scout 的选择对下游 VQA 准确率影响非平凡。
- **注意力分数存储开销**：PruneKV 需在预填充阶段存储所有层的注意力分数，本身引入额外内存开销。

### 8.2 实验与应用的局限
- **VS 任务增益有限**：ROUGE-L 指标下各方法差距较小，VisCache 在 ActCap 上偶有轻微下降，说明对摘要类任务的增益有待加强。
- **融合策略的敏感性**：μ = 0.7 为经验最优，μ 过小导致信息保留不足，过大引入噪声，需要针对不同模型调参。
- **截断层 h 的选取**：依赖经验确定（3/4 深度），不同架构可能需要重新验证。
- **隐私与伦理风险**：效率提升可能使大规模视频监控等应用更易部署，需关注隐私和公平性问题；方法依赖预训练模型注意力模式，可能继承其固有偏差。
