## 摘要
解析持续学习已成为基于梯度的类增量学习的一种强无样本替代方案，因为它用闭式岭更新取代了迭代优化。然而，通常以随机梯度覆盖为中心的遗忘叙述，并不能解释为何解析方法尽管使用精确递归求解器，仍会在旧类别上发生漂移。我们将罪魁祸首确定为谱干扰：所有任务的联合岭分类器共享逆自相关算子$(R+λI)^{-1}$，因此新任务样本若加载到旧的主导特征方向上，会稀释谱并扰动旧类别的逻辑值，即使旧标签从未被重新访问。基于这一观点，我们提出SPARCL，一种谱分区解析持续学习器，它将运行中的自相关分解为高能核心和残差补集，冻结核心子空间中的旧类别分类器组件，并通过递归最小二乘及其可选的残差随机投影扩展仅更新残差块。这产生了一个简单的闭式更新，并对旧逻辑值的核心贡献具有可证明的不变性保证。在冻结ViT-B/16协议下的CIFAR-100、CUB-200、ImageNet-R和ImageNet-A上，SPARCL缩小了经典解析学习器与强表示匹配器之间的大部分差距，同时与稀疏特征去相关方法（如Fly-CL）保持互补。

## Abstract
Analytic continual learning has emerged as a strong exemplar-free alternative to gradient-based class-incremental learning because it replaces iterative optimization with closed-form ridge updates. Yet the usual forgetting narrative, centered on stochastic gradient overwriting, does not explain why analytic methods still drift on old classes despite exact recursive solvers. We identify the culprit as spectral interference: the joint ridge classifier for all tasks shares the inverse autocorrelation operator $(R+λI)^{-1}$, so incoming task samples that load onto old dominant eigendirections dilute the spectrum and perturb old-class logits even when old labels are never revisited. Based on this view, we propose SPARCL, a spectral partitioned analytic continual learner that decomposes the running autocorrelation into a high-energy core and a residual complement, freezes old-class classifier components in the core subspace, and updates only the residual block through recursive least squares with an optional residual random-projection expansion. This yields a simple closed-form update with a provable invariance guarantee for the core contribution of old logits. Across CIFAR-100, CUB-200, ImageNet-R, and ImageNet-A under a frozen ViT-B/16 protocol, SPARCL closes most of the gap from classical analytic learners to strong representation matchers, while remaining complementary to sparse feature-decorrelation approaches such as Fly-CL.

## 1. 论文的核心问题与整体含义

- **研究背景**：类增量学习（CIL）的目标是在不重新训练旧数据的前提下持续学习新类别，同时避免灾难性遗忘。传统解释将遗忘归因于 SGD 迭代优化对旧参数的直接覆写。
- **核心问题**：解析持续学习（Analytic CIL）以闭式岭回归（闭式更新）取代梯度迭代，理论上不应存在“参数覆写”，但实验发现旧类别精度仍会下降。论文提出一个此前被忽视的机制——**谱干扰（spectral interference）**：
  - 所有任务共享同一个全局逆自相关算子 $(R_t + \lambda I)^{-1}$；
  - 新任务样本如果在旧的主导特征方向（高能量特征方向）上有负载，会改变该算子的特征值分布，导致旧方向上的逆增益被“稀释”；
  - 即便旧类别的交叉相关项 $C_{\text{old}}$ 从未改变，旧类别的 logits 仍会因共享算子几何变化而发生系统性漂移。
- **整体含义**：这篇文章重新定义了“解析持续学习中的遗忘机制”，说明遗忘并非梯度优化的专利，而是来源于共享逆算子的谱结构变化。这一视角有助于设计真正的几何不变更新规则。

## 2. 提出的方法论：SPARCL

- **核心思想**：将特征空间的累积自相关矩阵 $R_t$ 的 eigenspectrum（特征谱）分解为两部分：
  - **高能核心（core）子空间**：由能量占比达到阈值 $\tau$ 的若干主导特征向量张成，承载历史任务的主要表示能量；
  - **残差（residual）子空间**：剩余低能量方向构成的补集，用于容纳新知识的塑性。
- **关键操作**：
  1. **谱分解与分区**：在每个（或每隔若干）任务结束时对 $R_{t-1}$ 做特征分解 $R_{t-1}=U\Lambda U^\top$，选择最小 $k$ 使得前 $k$ 个特征值能量占比 $\geq \tau$，定义核心投影器 $P_\parallel = U_k U_k^\top$ 和残差投影器 $P_\perp = I - P_\parallel$。
  2. **核心冻结**：旧类别分类器权重中位于核心子空间的部分 $W^{\text{old}}_{t-1,\parallel}$ 被永久冻结，不再被后续任务更新。
  3. **残差更新**：仅残差子空间中的分类器部分通过递归最小二乘更新：$\tilde{W}_t = (\tilde{R}_t + \lambda P_\perp)^\dagger \tilde{C}_t$，其中 $\tilde{R}_t = P_\perp R_t P_\perp$，$\tilde{C}_t = P_\perp C_t$。
  4. **可选残差随机投影扩展**：在残差子空间内随机采样正交方向 $Q_t$（满足 $P_\parallel Q_t=0$），以增加残差容量，类似于 RanPAC 的随机投影但只作用于残差块。
- **算法流程**（文字概括）：
  1. 维护 ACIL 式统计量 $R_t, C_t$；
  2. 根据 $R_{t-1}$ 计算核心/残差投影器；
  3. 冻结旧类核心系数；
  4. （可选）构造残差随机投影；
  5. 在残差子空间求解岭回归；
  6. 合并冻结核心与更新后的残差权重。
- **理论保证**：
  - 定理 1：旧类别 logits 中核心部分的贡献严格不变；总漂移被残差特征能量上界约束。
  - 命题 1：形式化谱干扰漂移公式，说明漂移幅度正比于新任务在旧主导方向上的谱负载 $\delta_i$。
- **效率实现**：采用块 Woodbury 更新，避免全维度矩阵求逆；仅对残差块做逆更新，计算复杂度由 $O(d^3)$ 降至 $O((d-k)^3)$。

## 6. 主要结论与发现

- **遗忘机制的新解释**：解析持续学习的旧类遗忘源于谱干扰，而不是梯度覆写。新任务在旧主导方向上的谱负载会“稀释”共享逆算子的增益，导致旧 logits 漂移。
- **SPARCL 作为有效干预**：通过冻结高能核心子空间中的旧类系数，可以在闭式更新框架内提供可证明的旧类 logits 不变性保证，同时保留残差子空间的塑性。
- **性能结论**：SPARCL 在四个基准上均优于所有基线，尤其在域偏移场景中大幅缩小经典解析方法与强表示匹配器的差距。
- **与 Fly-CL 的互补性**：Fly-CL 在特征稀疏编码层面做去相关，SPARCL 在逆算子谱层面做保护，两者可组合（未来工作：在残差带内使用 Fly-CL 式稀疏扩展）。

## 7. 优点

- **理论创新**：首次系统揭示了解析持续学习中的“谱干扰”机制，并给出简洁的漂移公式与不变性定理，理论贡献扎实。
