## 摘要
虽然通用VLM的训练成本高昂，但通常认为创建领域专家需要对日益庞大的基础模型进行微调。我们表明，在兽医放射学中，这一假设是错误的。通过重新思考整个VLM流程——从文本分词、预训练到接地和推理——我们证明了精心的工程可以从零开始产生性能优于大得多的基础模型的模型，且不依赖任何其他数据。我们的方法引入了新的生成式预训练和接地策略，提高了训练效率，提升了数据利用率和下游性能。仅使用当代通用模型参数、数据和计算量的一小部分，我们开发了第一个能够为兽医X光片生成诊断报告的VLM，在该任务上显著超越了开放基础模型。

## Abstract
While generalist VLMs are expensive to train, creating domain experts is widely assumed to require fine-tuning increasingly large foundation models. We show that, in veterinary radiology, this assumption is misguided. By rethinking the entire VLM pipeline - from text tokenisation and pre-training to grounding and inference - we demonstrate that careful engineering can yield models that outperform much larger foundation models from scratch, without relying on any other data. Our approach introduces new strategies for generative pre-training and grounding that improve training efficiency, increasing data utilisation and downstream performance. Using only a fraction of the parameters, data, and compute of contemporary generalist models, we develop the first VLM capable of generating diagnostic reports for veterinary radiographs, surpassing open foundation models on this task by significant margin.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **整体思想**：把 VLM 管道看作四个可优化的环节——分词、预训练、训练、推理，并在每个环节上都针对专家领域做定制化设计，而不是沿用通用模型的默认配置。

- **文本分词（Tokenisation）**：
  - 先将文本统一转为小写，并用 LLM 修正拼写错误。
  - 采用“词级分词 + 后续 BPE”的方法，构建 32,768 个 token 的专属词表。
  - 效果：平均文本长度从约 520 字符压缩到 30.8 个 token（约 16.9 字符/token），而 GPT 系列的 tokenizer 平均需要 106 个 token（约 4.9 字符/token），序列长度缩短约 6 倍。
  - 作者用公式 `P(error)=1-(1-e)^T` 说明序列长度减半可使无错误生成概率显著提升（e=0.02, T=20 时从约 66% 提升到 81%）。

- **模型架构**：
  - 采用标准 decoder-only Transformer，输入序列为“图像 token 序列 + 报告文本 token 序列”。
  - 图像 token 使用 RAPTOR 嵌入（一种在兽医数据上训练的 DINO-CLIP 混合特征），而非简单线性投影。RAPTOR 特征使模型收敛更快、性能更高。
  - 图像 token 使用 2D 正弦位置编码，文本 token 使用 1D 正弦位置编码；额外添加“图像/文本”类型嵌入以区分两种 token。
  - 训练时，图像 token 部分全可见（mask 置 0），只对文本 token 做自回归预测。

- **可选预训练（Generative Pre-training）**：
  - 目标：利用无标签图像数据，提高数据利用率，加速收敛。
  - 方法：先将图像嵌入（RAPTOR 特征）离散化为 token，再自回归地预测下一个图像 token。
  - 离散化采用**二进制子空间量化**（Binary Subspace Quantisation）：学习一个低秩投影矩阵 A，把高维向量投影到 n 维子空间，再按符号位（sign）生成 2^n 个桶作为离散索引。相比 k-means，该方法将每个点的分配复杂度从 O(Kd) 降到 O(nd)，例如 K=4096, d=128 时，计算量从 524,288 次乘法降至 1,536 次，降低两个数量级以上。
  - 预训练时输入未量化嵌入，但预测目标为量化后的离散结果，与后续微调阶段使用未量化嵌入保持一致。

- **正式训练**：
  - 优化器采用 **schedule-free Adam**（rectified Adam），无需学习率调度。
  - 流程：先固定编码器、只训练预测头 1500 步，再逐步 warmup 学习率 1500 步。
  - 训练时随机将 1/32 的图像 token 置零，以便在推理阶段通过 IFG 放大图像影响。

- **推理阶段改进**：
  - **Image-Free Guidance (IFG)**：借鉴扩散模型中的 classifier-free guidance，每次预测时同时计算“有图像”和“无图像”的 token 概率，放大图像带来的信号差异。公式为：
    ```
    P_IFG(t, I) = P(t, I) + s · (P(t, I) − P(t, ∅))
    ```
    其中 s 为放大因子，随后归一化并采样。
  - **多图像预测**：无需重新训练，对多张图像分别推理后按 token 概率取最大值，可使 top-1 准确率提升最多 0.03。
  - **可解释性**：使用 Integrated Gradients 方法计算每个文本 token 对图像区域的贡献，生成热力图（如“cardiac”对应心脏区域），便于兽医验证模型关注区域。

## 3. 实验设计：数据集 / 场景、benchmark、对比方法

- **数据集**：约 1500 万（15M）文本-图像对，来自兽医 X 光影像和相应兽医诊断报告，全部为专有数据。实验中还使用了 0.1M、0.5M、3M 等子集进行效果评估。
- **任务场景**：给定兽医 X 光图像，生成结构化的诊断报告文本。
- **评估基准**：
  - 主要指标为**微 F1 分数**：将真实报告和生成报告分别交给 OpenAI o3，让其从固定目录中提取发现的异常列表，再计算两者的全局 micro-F1。
  - 次要指标：下一文本 token 预测的 top-1/top-5 准确率、困惑度（perplexity）。
- **对比方法**：
  - 通用闭源模型：OpenAI o3（未微调）。
  - 通用 VLM：PaliGemma，微调方式包括 LoRA 和全量微调（含不同规模变体）。
  - 消融对照：是否使用 RAPTOR 特征、不同预训练量化中心数、是否使用 IFG、不同数据规模等。

## 6. 论文的主要结论与发现

- 从头训练的小型专家 VLM（约 1B 以内参数）可以在兽医 X 光报告生成任务上，**大幅超越未微调的通用大模型（如 o3）以及微调后的 PaliGemma（13B/53B）**。
- 关键成功因素包括：
  - 领域专属分词（大幅缩短序列长度，降低误差率与计算开销）；
  - 使用 RAPTOR 这类针对数据预训练的图像嵌入（比 DINO 或线性投影明显更优）；
  - 基于二进制子空间量化的生成式预训练（利用无标注数据，提高数据利用率）；
  - 推理阶段的 IFG 技术（对抗语言先验，增强图像 grounded 程度）。
- 作者由此断言：**“微调大型通用模型是唯一可行路径”这一普遍假设在兽医放射学中是错误的**，并为低成本构建专用 VLM 提供了可复制的“最佳实践配方”。
