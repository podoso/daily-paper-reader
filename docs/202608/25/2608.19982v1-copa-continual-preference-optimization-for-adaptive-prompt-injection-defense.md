## 摘要
大型语言模型（LLM）仍然容易受到提示注入攻击，攻击者将对抗性指令嵌入用户输入或外部内容中，从而操纵模型行为并绕过安全防护。现有防御手段大多为静态的，依赖于固定的对齐目标或针对特定攻击的过滤机制，这些机制在新攻击策略出现时需要重新设计。尽管近期提出的终身对齐方法能够应对用户偏好的变化，但它们并未考虑自适应攻击者，这些攻击者会不断演变以利用先前所学防御中的弱点。这一局限性在实际部署中尤为重要，因为不断演变的攻击分布要求持续适应，同时不能牺牲对已遇到威胁的鲁棒性。我们提出了COPA，一种将提示注入防御视为终身学习问题的持续偏好优化框架。COPA并非一次性对齐，而是通过基于GRPO的优化，逐步整合来自新观察到攻击的反馈，并使用边际加权经验重放来保留对先前攻击类别的防御能力。这使得模型能够持续适应新兴威胁，同时缓解灾难性遗忘并保持通用模型能力。在终身提示注入攻击流中，与最先进的防御方法相比，COPA将攻击成功率平均降低了最多6.3倍和4.4倍。这些结果凸显了持续偏好优化作为防御LLM免受自适应攻击者攻击的有效范式。

## Abstract
LLMs remain vulnerable to prompt injection attacks, where adversarial instructions embedded in user inputs or external content manipulate model behavior and bypass safeguards. Existing defenses are predominantly static, relying on fixed alignment objectives or attack-specific filtering mechanisms that require redesign as new attack strategies emerge. While recent lifelong alignment methods address shifting user preferences, they do not account for adaptive adversaries that continually evolve to exploit weaknesses in previously learned defenses. This limitation is particularly important in real-world deployments, where evolving attack distributions necessitate continual adaptation without sacrificing robustness to previously encountered threats. We present COPA, a continual preference optimization framework that treats prompt-injection defense as a lifelong learning problem. Instead of one-time alignment, COPA incrementally incorporates feedback from newly observed attacks via GRPO-based optimization and uses margin-weighted experience replay to retain defenses against prior attack classes. This enables continuous adaptation to emerging threats while mitigating catastrophic forgetting and preserving general-purpose model capabilities. Across lifelong prompt injection attack streams, COPA reduces attack success rate by up to 6.3x and 4.4x on average compared to state-of-the-art defenses. These results highlight continual preference optimization as an effective paradigm for defending LLMs against adaptive adversaries.

### 1. 核心问题与整体含义（研究动机与背景）

大型语言模型（LLM）在真实部署中高度脆弱，容易遭受**提示注入攻击（Prompt Injection Attack）**——攻击者将恶意指令嵌入用户输入或外部内容（如检索文档、工具输出）中，操纵模型行为并绕过安全机制。此类威胁在实践中已被证实会影响 GitHub Copilot、Microsoft Copilot 等生产系统，且被 OWASP 列为 LLM 应用中的头号安全风险。

尽管已有多种防御手段，但主要分为两类：
- **基于对齐的防御**（如 SecAlign）：通过偏好优化一次性训练模型区分合法指令与注入指令；
- **基于过滤器的防御**（如 LlamaGuard、DataSentinel）：通过分类器检测并拦截恶意输入。

这些方法都是**静态设计**的——针对固定的攻击分布进行一次性优化，当新的攻击策略出现时需重新设计或重新训练。近期提出的终身对齐方法（如 Lifelong Safety Alignment）虽能适应偏好的偏移，但仍未专门应对**自适应攻击者（adaptive adversaries）**，即那些不断演化以绕过已学防御策略的攻击。

> 核心缺口：**没有一种现有防御能够在攻击分布动态变化时持续保持鲁棒性**，且同时不遗忘已学防御。COPA 正是针对这一关键空白，将提示注入防御重新定义为**持续安全对齐（continual security alignment）**问题。

### 2. 论文提出的方法论

#### （1）核心思想

COPA 将提示注入防御视为一个**终身学习（lifelong learning）**问题，而非一次性优化。通过在攻击变体流上顺序更新防御模型，兼顾三个目标：
- **鲁棒性（Robustness）**：对新近观察到的攻击变体有效；
- **保持性（Retention）**：不遗忘对先前攻击变体的防御能力（避免灾难性遗忘）；
- **泛化性（Generalization）**：对未见过的攻击变体保持防御力。

#### （2）关键组成与技术细节

| 模块 | 作用 | 核心技术 |
|------|------|----------|
| **Stage 1: 偏好对齐** | 建立一致的网络安全基线，使不同初始化的模型在同一起跑线上进入持续学习 | 使用 DeepTeam 网络安全偏好数据 D0（102 对），通过 **GRPO** 进行偏好优化；模型冻结，仅训练 **LoRA** 低秩适配器 |
| **Stage 2: 持续对抗训练** | 按攻击变体顺序（A1~A9）逐步适应新攻击，同时保持旧防御 | 基于 GRPO 的持续优化 + **边际加权经验重放（margin-weighted replay）** |
| **重放优先信号** | 衡量模型当前对某攻击样本的防御自信度 | 对数似然边际（log-likelihood margin）：m_θ(x, y_s, y_u) = log π_θ(y_s|x) − log π_θ(y_u|x)，边际低意味着防御脆弱 |
| **边际加权重放缓冲** | 让模型重点回顾最薄弱的旧攻击样本 | 按 softmax(exp(−m_b / η)) 概率采样低边际样本，每任务开始时对缓冲中的边际进行刷新避免过期，且按变体分桶以保证重放均衡 |

#### （3）核心公式

COPA 使用 **GRPO 目标**（Group Relative Policy Optimization）进行策略更新，其优势在于用组内归一化处理稀疏的二元安全奖励，训练稳定：

\[
\mathcal{L}_{GRPO} = -\mathbb{E}\left[\frac{1}{G}\sum_{i=1}^{G}\min(\rho_i \hat{A}_i, \text{clip}(\rho_i)\hat{A}_i) - \beta D_{KL}(\pi_\theta \|\pi_{ref})\right]
\]

其中优势函数 \(\hat{A}_i\) 由组内奖励归一化得到；整体优化目标为：

\[
\mathcal{L}_{COPA}(\theta; t) = \mathcal{L}_{GRPO}\left(\theta; \mathcal{D}_t \cup \mathcal{R}_t\right)
\]

即每一阶段将**新攻击数据**与**优先重放的旧数据**混合，同时优化对新型攻击的适应与对旧攻击的保持。模型基座完全冻结，仅更新 LoRA 参数。

### 6. 主要结论与发现

1. **鲁棒性显著提升**：COPA 在全序列上达到 ASR=0.035，比 SecAlign（0.221）低 6.3 倍，比最强的基线 LlamaGuard（0.104）低约 3 倍；比 DataSentinel（0.132）降低更多；
2. **遏制灾难性遗忘**：COPA 的 BWT=+0.028（正值，表示不仅没遗忘还在增强），而所有基线均为负值（如 SecAlign 为 −0.176），表现出生显著的忘记现象；
3. **全程防御一致性好**：COPA 的 AP=0.850，远超最优的基线（0.694），意味着模型在整个持续学习过程中的防御质量波动小；
4. **不牺牲通用能力**：在 GPQA（0.310）和 MMLU（0.340）均达到最优，与未防御基座模型（0.300/0.332）持平甚至更高，而静态防御牺牲了最多 49% 的推理精度；
5. **架构无关性**：三个异构基座（Llama/Mistral/Qwen）上表现一致（ASR 0.035~0.054），表明方法可移植性强；
6. **组件必要性**：去掉 margin 加权重放（→uniform）后 ASR 从 0.035 恶化至 0.163，AP 从 0.850 降至 0.600；用 DPO 替代 GRPO 后 ASR 高达 0.335，BWT 为 −0.231，证明这两个设计缺一不可。

### 7. 优点

1. **问题定义精准**：将提示注入防御正确定位为一个对抗性终身学习问题，明确区分了"偏好偏移"与"攻击演化"的不同——后者包含主动尝试突破已学防御的对抗性意图；
2. **方法论创新**：用 GRPO 的偏好边际（preference margin）作为模型不确定性的**免标注信号**，引导重放聚焦于最薄弱环节，这一思路简洁且高效；
3. **工程实现务实**：冻结基座 + LoRA 适配器 + 4-bit 量化，使持续防御在单卡 A100 上即可运行，部署成本低，适合真实环境；
4. **评估框架周密**：三场景递进式评测（族内→族外→优化攻击）+ 三指标互补（ASR 看效果、BWT 看记忆、AP 看全过程）+ 双基准看通用能力，兼顾了鲁棒性、持久性、整体性和实用性；
5. **公平性设计良好**：所有基线获得同等终身学习机会，公平地凸显了 COPA 的差异化价值。

### 8. 不足与局限

1. **实验规模有限**：仅基于 7B/8B 规模的模型验证，未包含更大尺寸模型（如 70B、405B），而真实企业部署中大型模型的动态可能不同；训练数据量也较小（D0 仅 102 条偏好对）；
2. **攻击流设计单一**：只采用一种固定顺序的攻击变体流，缺少随机化顺序或多任务交错（task interleaving）的实验，无法排查顺序依赖性问题；
3. **重放机制未充分调优**：缓冲大小（60）、温度 η、边际更新频率等关键超参数均未做系统敏感性分析；
4. **泛化场景有限**：未覆盖多语言注入、越狱与注入的混合攻击、多模态输入（图像/音频中的注入）等实际可能面临的复杂场景；
5. **未讨论评估器的可靠性**：GRPO 依赖二元安全审判器（safety judge）作为奖励信号，但论文未分析该审判器在对抗样本上的准确率与稳健性，它可能成为新的薄弱环节；
6. **安全隐患**：使用"红队攻击"数据持续优化模型，可能嵌入攻击模式相关的知识，存在被反向利用的潜在风险（虽然从结果看通用能力未损，但论文未探讨这一问题）；
7. **训练成本细节缺失**：论文只描述了 GPU 配置，未报告训练时间、token 消耗量或具体能耗，复现和成本评估有一定困难。
