## 摘要
知识型视觉问答（KB-VQA）依赖于检索外部信息来回答涉及长尾实体的查询。然而，现有的检索流程主要采用CLIP风格的双编码器，这些编码器更注重表面视觉相似性而非实体级语义对齐。当语义相同的概念表现出较大的视觉差异，或不同实体在视觉上相似时，这种范式常常失效。为解决此问题，我们提出了KBMR，这是首个专为KB-VQA定制的基于MLLM的嵌入检索器。利用MLLM强大的自回归能力，KBMR将图像映射到更能保留概念身份的语义空间。为了应对维基百科规模检索中噪声监督的挑战，我们引入了一种基于MLLM的语义鉴别器，生成连续的实体一致性权重。这些权重指导了一种新颖的连续语义蒸馏目标，从而能够在严格的二值标签之外实现有效的困难负样本采样和软监督。大量实验表明，KBMR显著优于CLIP基线，在检索Recall@1上提升了高达14.7%，在端到端VQA准确率上提升了9.4%。代码可在https://github.com/realHarryX/KBMR获取。

## Abstract
Knowledge-Based Visual Question Answering (KB-VQA) relies on retrieving external information to answer queries involving long-tail entities. However, existing retrieval pipelines predominantly employ CLIP-style dual encoders, which prioritize surface-level visual similarity over entity-level semantic alignment. This paradigm often fails when semantically identical concepts exhibit large visual variations or when distinct entities appear visually similar. To address this, we propose KBMR, the first MLLM-based embedding retriever tailored for KB-VQA. Leveraging the robust autoregressive capabilities of MLLMs, KBMR maps images into a semantic space that better preserves concept identity. To tackle the challenge of noisy supervision in Wikipedia-scale retrieval, we introduce an MLLM-based semantic discriminator that generates continuous entity-consistency weights. These weights guide a novel continuous semantic distillation objective, enabling effective hard negative sampling and soft supervision beyond rigid binary labels. Extensive experiments demonstrate that KBMR significantly outperforms CLIP baselines, yielding up to a 14.7% improvement in retrieval Recall@1 and a 9.4% gain in end-to-end VQA accuracy. Code is available at https://github.com/realHarryX/KBMR.

## 1. 核心问题与整体含义

- **研究背景**：知识型视觉问答（KB-VQA）需要借助外部知识库（如维基百科）回答涉及长尾实体、无法仅从图像推断的问题。标准流程先用图像检索候选知识条目，再经重排、过滤和答案生成。
- **现有瓶颈**：目前绝大多数 KB-VQA 系统用 CLIP 风格的双编码器做第一阶段检索。CLIP 强调表面视觉相似性，却无法处理“同一实体有较大视角/时间/风格差异”或“不同实体视觉上高度相似”的情况，导致实体混淆和错误候选召回。
- **核心问题**：KB-VQA 的检索本质是实体级语义匹配，而非像素级视觉匹配。若检索空间仍建立在视觉相似性上，下游推理和答案生成会被候选池质量限制。
- **论文主张**：应让检索器学习“实体对齐”的语义空间，而不是仅仅追求视觉相似。为此提出 KBMR——首个针对 KB-VQA 的基于多模态大语言模型（MLLM）的嵌入检索器。实验表明，KBMR 在检索 Recall@1 上最高提升 14.7%，在端到端 VQA 准确率上最高提升 9.4%。

## 2. 方法论：核心思想与关键技术

### 2.1 总体思路
- 利用 MLLM 的自回归语义编码器替代 CLIP 作为图像检索器，使图像嵌入更接近“概念身份”而非浅层外观。
- 引入一个 MLLM 作“语义判别器”（Semantic Discriminator），输出**连续实体一致性权重**，用于：
  - 指导高质量、多样化的困难负样本采样；
  - 提供比硬标签更丰富的软监督信号。
- 提出**连续语义蒸馏**（Continuous Semantic Distillation）训练目标，将检索器的相似度分布与判别器诱导的语义先验分布对齐，从而使检索空间具备实体级判别力。

### 2.2 MLLM 嵌入检索器
- 使用提示词 `<Image> Summary above image in one word:\n` 让 MLLM 将图像摘要到共享语义空间。
- 取最后一个 token 的隐藏状态作为图像嵌入，再经过归一化得到检索向量。

### 2.3 语义判别器与实体一致性权重
- 对查询图像和候选图像构造指令：“判断 Query 和 Candidate 是否指向同一实体，回答 Yes/No”。
- 从 Yes 和 No token 的对数几率（logits）计算权重：
  \[
  w_i = \sigma\left(\frac{z_{i,y} - z_{i,n}}{\gamma}\right)
  \]
  其中 \(\sigma\) 为 sigmoid，\(\gamma\) 为语义锐度系数（控制权重平滑度）。
- 该权重连续地表达“查询-候选”之间的实体语义对齐程度，而不是二值标签。

### 2.4 困难负样本采样
- **候选池构建**：先用 EVA-CLIP 生成查询与所有知识图像嵌入，检索 Top-50 相似候选（排除正样本），得到潜在困难负样本集合 \(\Omega_p\)。
- **语义过滤**：用语义判别器计算每个候选与查询的一致性权重，并设定阈值 \(\alpha = w_{q,c_t} - \beta\)（\(w_{q,c_t}\) 是查询与真实正样本的权重），剔除高于阈值的易混淆候选。
- **分层采样**：将剩余候选按权重分成 4 个难度层级，每层随机抽取 2 个，固定得到 8 个困难负样本；若不足则复制补充；若无任何有效负样本则丢弃该训练样本。

### 2.5 连续语义蒸馏训练
- 将检索器输出视为候选集上的概率分布：
  \[
  p_q(j) = \frac{\exp(\text{sim}(e_q, e_j)/\tau)}{\sum_{e \in E_c} \exp(\text{sim}(e_q, e)/\tau)}
  \]
- 将语义判别器权重转化为软语义先验：
  \[
  s_q(j) = \frac{\exp(w_{q,c_j}/\tau)}{\sum_{c \in \Omega_c} \exp(w_{q,c}/\tau)}
  \]
- 用**对称 KL 散度**作为损失：
  \[
  \mathcal{L}_{\text{CSD}} = \mathbb{E}_{q \sim D}\left[\frac{1}{2}\left(D_{KL}(p_q \| s_q) + D_{KL}(s_q \| p_q)\right)\right]
  \]
- 该目标既驱使检索器把概率质量放到语义正确候选上，又防止分布过于尖锐，从而提高优化稳定性。

## 6. 主要结论与发现

- 在 E-VQA、InfoSeek 和 OK-VQA 上，KBMR 均一致优于 CLIP 检索器与通用 MLLM 检索器。

- 可视化说明：KBMR 能把正确实体放在首位，而 CLIP 会被视觉相似但语义不匹配的样本干扰。
- 总体结论：KB-VQA 检索应明确建模实体级语义关系，而不是停留在表面视觉匹配；MLLM 加软蒸馏训练能有效改善候选池质量，为下游推理提供更可靠证据。

## 8. 局限性

- **对语义判别器的依赖**：训练流程需要一个额外的 MLLM 判别器来生成权重。虽然该方法在实验中表现良好，但判别器本身的误差会传导到采样和蒸馏信号中；若判别器在极端长尾实体上判断不准，检索器的上限也会被拉低。
- **MLLM 编码器的效率问题**：MLLM 自回归编码比 CLIP 双编码慢得多。论文未报告推理时延和索引构建成本，在大规模知识库（如数百万 Wikipedia 条目）上做实时检索时，计算开销可能成为部署瓶颈。
- **检索与生成的验证范围**：虽然替换检索器在多个下游系统上一致带来提升，但所有端到端测试都基于现有流水线的固定生成器；检索器与生成器联合微调的效果尚未探索，理论上仍有进一步提升空间。
- **跨域泛化存疑**：训练数据仅来自 E-VQA、InfoSeek 和 OK-VQA 三个数据集，且 OK-VQA 上的 VQA 分数只基于 OMGM 流水线验证。对于更开放域、多语言或视频类知识问答的适用性，论文没有给出证据。
- **对“实体”的定义依赖知识库结构**：KBMR 的实体对齐信号源于维基百科式条目结构（以页面为实体单元）。如果知识库的实体粒度不同（如细粒度属性级实体或事件型实体），判别器指令和蒸馏目标需要重新设计。

## 9. 深层讨论

- **检索任务的再定义**：本文的深层贡献在于把 KB-VQA 的检索从“图像相似度排序”重构为“实体身份对齐”。这种视角对多模态检索社区具有迁移意义：CLIP 类模型做图文匹配的瓶颈可能不是容量不足，而是训练目标没有对准下游任务所需的语义粒度。
- **软监督 vs. 硬标签**：论文用连续的实体一致性权重替代二元标签，本质上把“同一实体”建模为程度问题而非类别问题。这与知识图谱补全中常用的“可信度软标签”思路同构，但被首次引入多模态检索训练，具有方法论新颖性。
- **MLLM 作为判别器的自举风险**：检索器用 MLLM 的判别信号训练，而 MLLM 本身也可能存在视觉幻觉或事实错误。虽然实验证明判别器比 CLIP 更可靠（AUC 0.91 vs. 0.79），但这是一种“用大模型监督小模型”的自举式训练，长期看需要更干净的监督来源或更强的容错机制。
- **工程可行性的权衡**：LoRA 微调、DeepSpeed ZeRO-2、1024 的累积 batch size 表明方案在工程上是可控的，但 8×A100 的算力门槛仍高于多数研究组。将 KBMR 蒸馏为更轻量的双塔结构、或利用缓存机制加速推理，是后续值得探索的方向。
