## 摘要
组合图像检索（CIR）是内容基于图像检索中的一种新兴范式，它允许用户通过将参考图像与辅助模态（通常是基于文本的）相结合来构建组合式查询。该方法支持细粒度搜索，其中目标图像与用户提供的图像共享结构元素，同时融入辅助文本所指定的修改。传统CIR方法依赖多模态融合将视觉和文本特征组合成联合查询嵌入，这需要训练模块来使组合查询与目标对齐。在本工作中，我们提出了PeFuse（伪融合），一个无训练框架，利用预训练的扩散模型和多模态大语言模型通过生成式转换来桥接模态。我们引入了两种新颖策略：单向转换和双向转换，将CIR转换为四个单模态检索问题。这些方法将CIR重新表述为模态内或跨模态的单查询检索任务，从而无需专门的任务特定训练。在标准基准上的大量实验表明，将CIR转换为文本到图像检索任务比替代转换策略更有效，与最先进方法相比达到了竞争性或更优的性能，同时由于转换管道的组件可替换而保持高灵活性。这些结果凸显了伪融合范式在零样本CIR中的有效性。我们的代码公开于：https://github.com/StevenXuf/PeFuse4CIR。

## Abstract
Composed Image Retrieval (CIR) is an emerging paradigm in content-based image retrieval that enables users to formulate compositional queries by combining a reference image with an auxiliary modality, usually text-based. This approach supports fine-grained search where the target image shares structural elements with the user-provided image while incorporating the modifications specified by the auxiliary text. Conventional CIR methods rely on multimodal fusion to combine visual and textual features into a joint query embedding, which requires training modules that align composed queries with the targets. In this work, we propose PeFuse (for pseudo-fusion), a training-free framework that leverages pretrained Diffusion Models and Multimodal Large Language Models to bridge modalities via generative conversion. We introduce two novel strategies: uni-directional and bi-directional conversion, which convert CIR into four single-modality retrieval problems. These methods reformulate CIR as either intra-modal or cross-modal single-query retrieval tasks, bypassing the need for dedicated task-specific training. Extensive experiments on standard benchmarks demonstrate that converting CIR into text-to-image retrieval tasks is more effective than alternative conversion strategies, achieving competitive or superior performance compared with state-of-the-art methods, while maintaining high flexibility thanks to replaceable components of the conversion pipeline. These results highlight the effectiveness of the pseudo-fusion paradigm for zero-shot CIR. Our code is publicly available at: https://github.com/StevenXuf/PeFuse4CIR.

### 一、核心问题与整体含义（研究动机与背景）

- **组合图像检索（Composed Image Retrieval, CIR）** 是内容图像检索的一种新兴范式：用户提供一张参考图像 + 一段辅助文本（如"把这双鞋换成红色"），系统需检索出符合图像结构且体现文本修改的目标图像。
- **核心挑战**：需要将视觉与文本两种异质模态融合为一个联合查询嵌入，传统方法依赖**任务特定的多模态融合训练**，例如训练一个网络对齐组合查询与目标图像嵌入。
- **现有方法的不足**：
  - 训练成本高，需要大量带人工标注的CIR三元组数据；
  - 泛化能力差，难以迁移到新领域/新数据集；
  - 融合模块通常是黑盒，解释性差且组件难以替换。
- **本文的研究意义**：探索一个**无需训练**的CIR新范式——通过预训练生成模型（扩散模型 + 多模态大语言模型）将"组合查询"**生成式地转换**为单一模态表示，从而绕开多模态融合训练，实现零样本CIR，并保持组件灵活可替换。

### 二、方法论：PeFuse（伪融合）

- **核心思想**：用**生成式转换（Generative Conversion）**替代传统的**特征级融合（Feature Fusion）**，将组合查询"翻译"为单一模态的表示，使CIR退化为单查询检索任务。
- **关键技术组件**：
  1. **预训练扩散模型（Diffusion Model）**：用于从参考图像+文本生成修改后的"伪目标图像"，实现图像模态的转换。
  2. **多模态大语言模型（MLLM）**：用于从参考图像+文本生成描述性的"伪目标文本"，实现文本模态的转换。
- **两种转换策略**：

  | 策略 | 方向 | 做法 | 生成的检索任务 |
  |------|------|------|----------------|
  | **单向转换（Uni-directional）** | 图像→文本 | 用MLLM将参考图像+修改文本合成为目标图像的文字描述 | 文本到文本的检索（text-to-text retrieval） |
  | | 文本→图像 | 用扩散模型将参考图像+修改文本合成为伪目标图像 | 图像到图像的检索（image-to-image retrieval） |
  | **双向转换（Bi-directional）** | 同时做两种单向转换 | 融合两个方向的单一模态查询结果 | 文本到图像检索（text-to-image）与图像到文本检索（image-to-text）两种跨模态检索 |
- **四种单模态检索问题**：通过单向+双向的组合，CIR被重新表述为以下四类检索任务：
  1. 文本→文本检索：
     - 用MLLM把参考图+文本转换为目标描述文本，与候选图像的预生成文本描述（经MLLM或现有图像描述模型提前生成的）做匹配。
  2. 图像→图像检索：
     - 用扩散模型把参考图+文本"生成/编辑"为伪目标图像，与候选图像做图像特征匹配。
  3. 文本→图像检索（跨模态）：
     - 双向转换的文本侧：MLLM生成的文本描述直接作为文本查询，用CLIP-style跨模态模型检索图像。
  4. 图像→文本检索（跨模态）：
     - 双向转换的图像侧：扩散模型生成的伪目标图像作为图像查询，用CLIP-style模型对候选文本描述检索，再映射回图像。
- **伪融合（Pseudo-Fusion）的含义**：整个过程没有训练任何融合模块，仅通过预训练生成模型的"能力拼接"实现组合查询的合成，故称"伪融合"。
- **无需训练**：所有组件均为现成的预训练模型，无需在CIR数据集上进行任何梯度更新或微调。
