## 摘要
现代多模态检索增强生成（M-RAG）系统从根本上受限于传统简单图的二元连接范式，这种范式无法捕捉异质实体之间复杂的高阶关联，例如视觉图表、分散的文本描述及其底层数值数据之间的N元关系。此外，现有的细化策略往往依赖穷举式的整页重构来对齐跨模态信息，导致计算冗余过高，并在长文档处理中引入上下文噪声。本文提出Hyper-M2RAG，一种通过高阶超图表示学习重新定义多模态文档检索的新框架。我们首先将文档结构形式化为多模态超图，利用超边作为统一语义容器，封装文本、图像和表格之间的多路关联，从而超越点对点建模。为缓解物理分页造成的语义碎片化，我们引入锚点驱动的增量细化机制。该方法无需全局扫描，而是识别跨边界锚节点，并利用一跳邻域上下文重建其局部超拓扑。这种针对性细化以最小计算开销有效弥合跨页知识鸿沟。在多模态基准数据集上的广泛评估表明，Hyper-M2RAG在检索精度和生成连贯性上均显著优于现有最先进方法。我们的代码可在https://github.com/ShenAoChen2001/MMHRAG获取。

## Abstract
Modern Multimodal Retrieval-Augmented Generation (M-RAG) systems are fundamentally limited by the binary connectivity paradigm of traditional simple graphs, which fails to capture the intricate, high-order correlations among heterogeneous entities, such as the N-ary relationships between a visual chart, its scattered textual descriptions, and underlying numerical data. Furthermore, existing refinement strategies often rely on exhaustive, full-page reconstruction to align cross-modal information, leading to prohibitive computational redundancy and the introduction of contextual noise in long-form document processing. In this paper, we propose Hyper-M2RAG, a novel framework that redefines multimodal document retrieval through High-order Hypergraph Representation Learning. We first formalize the document structure as a Multimodal Hypergraph, utilizing hyperedges as unified semantic containers to encapsulate multi-way associations across text, images, and tables, thereby transcending point-to-point modeling. To mitigate semantic fragmentation caused by physical pagination, we introduce an Anchor-driven Incremental Refinement mechanism. Rather than performing a global sweep, our approach identifies boundary-crossing anchor nodes and reconstructs their local hyper-topology using one-hop neighborhood contexts. This targeted refinement effectively bridges cross-page knowledge gaps with minimal computational footprints. Extensive evaluations on multimodal benchmarking datasets demonstrate that Hyper-M2RAG significantly outperforms state-of-the-art methods in both retrieval precision and generation coherence. Our code is available at https://github.com/ShenAoChen2001/MMHRAG.

### 1. 核心问题与研究动机

- **研究背景**：文档问答（Doc-QA）正从纯文本理解发展为多模态长文档推理。真实场景中的学术论文、技术报告等常将关键证据分散在文本、图表、表格和页面布局中，需要跨页、跨模态的语义关联建模。
- **核心问题**：现有 RAG 系统存在两大结构性缺陷：
  - **二元连接假设失效**：传统图模型（如知识图谱）以 (head, relation, tail) 三元组表示关系，仅能刻画两两关联。但多模态文档中的关键证据往往是**N元高阶联合关联**——如图表、图例、正文段落和表格单元共同构成一个语义单元，简单二分边分解会破坏语料原有的整体语义完整性，导致证据碎片化。
  - **细化效率瓶颈**：现有方法（如 MegaRAG）在长文档中常通过全局重扫或整页重建来对齐跨模态信息，计算冗余高，且易在长文本处理中引入上下文噪声。
- **核心问题表述**：如何将 RAG 从基于图的成对检索拓展为基于超图的高阶多模态推理，同时保证长文档场景下的细化效率？

### 2. 方法论

#### 2.1 核心思想

提出 **Hyper-M2RAG**，将文档表示从"图-边"范式推进到"超图-超边"范式。核心包括三大组件：

1. **多模态数据摄入（PMU）**：以页面级多模态单元（Page-level Multi-modal Unit, PMU）为原子单位，不再将文档视为线性文本流。每个单元包含 OCR 文本、页面全局图像和局部图像块（图/表），搭配语义占位符保证视觉主导向页面的兼容，同时支持纯文本输入（视觉字段为 ∅）。
2. **两阶段多模态超图索引构建**：
   - **阶段一：页面级抽取与聚合**：对每个 PMU 用 LLM 抽取实体顶点 $V_i$、成对关系 $E_{i,low}$ 和高阶关联 $E_{i,high}$，并记录来源页码。再通过规范化合并操作构建初始全局超图 $G_{init}$。
   - **阶段二：锚点驱动增量细化**：识别跨页锚点 $V_{anc}=\{v \in V \mid |src(v)| \geq \tau\}$（高频跨页实体），提取其星扩展子图（star-expansion），仅对锚点出发的一跳邻域拓扑进行局部重构，生成跨页细化超边 $E_{refine}$，合并回全局超图。**不重扫全页，只做拓扑引导的局部手术**。
3. **认知启发的混合检索**：
   - 查询分解：MLLM 将查询分解为细粒度实体关键词 $K_{low}$ 和宏观主题关键词 $K_{high}$。
   - 双通道检索：
     - **路径 I（顶点锚定实体检索）**：基于 $K_{low}$ 在实体向量空间做相似检索，扩展入射超边获取局部上下文 $C_{ent}$；
     - **路径 II（超边定向关系检索）**：基于 $K_{high}$ 直接在高阶超边向量空间检索，回溯跨页来源与节点得到主题级上下文 $C_{rel}$。
   - 证据融合：将 $C_{ent}$ 与 $C_{rel}$ 融合为结构化证据包 $S$（实体 + 超边 + 多页来源块），交给 LLM 生成最终答案。

#### 2.2 关键技术公式

- 生成过程：$Y_{ans} = LLM_{gen}(y_i \mid y_{<i}, Q, S)$
- 超图结构：$G = (V, E)$，其中 $E = E_{low} \cup E_{high} \cup E_{refine}$
- 检索函数：$S = HyperRetriever(G, Q)$
- 锚点子图抽取：$E_{sub}(v) = \{e \in (E_{low} \cup E_{high}) \mid v \in e\}$，$V_{sub}(v) = \{u \in V \mid \exists e \in E_{sub}(v), u \in e\}$
- 细化生成：$E_{refine} = LLM_{ref}(R(G_{sub}(v), P_{ref}))$

### 6. 主要结论与发现

1. **超图优于二元图**：Hyper-M2RAG 在所有数据集和维度上稳定超越 GraphRAG、HyperRAG 和 MegaRAG。多模态场景优势最大——Sustainable Report 域对 MegaRAG 的 Overall 胜率达 88.8%，对 GraphRAG 达 77.6%。
2. **多模态场景收益最显著**：在文本域优势相对温和（Overall 胜率 22.4%~58.4%），但进入视觉密集数据后优势急剧扩大，说明布局感知超边确实捕获了传统图结构丢失的跨模态依赖。
3. **多样性（Diversity）与赋能性（Empowerment）增益突出**：高阶超边将分散的多模态实体聚类为统一语义单元，使检索器可单次遍历获取非局部、多跳连接。Sustainable Report 域的 Diversity 与 Empowerment 均达 90.4% 胜率。
4. **局部细化有效且高效**：锚点驱动细化将跨页关联的发现从全局扫描变为拓扑局部操作，Token 消耗降低 72%-77%，同时精度更高。
5. **模态增强 + 结构设计需协同**：结构分析显示简单加入多模态信息（HyperRAG+MM）反而减少了高阶超边（TechReport：2,078 vs HyperRAG 的 2,579），只有超图构建 + 锚点细化联合建模才能产生丰富的高阶结构（8,257 条）。

### 7. 优点

- **问题把握精准**：明确指出现有多模态 RAG 的缺陷不是"模态不够多"而是"关系假设不够高阶"，将问题提升到表示学习的层面，切中本质。
- **方法设计完整自洽**：从 PMU 数据摄入 → 两阶段超图构建 → 双通道检索 → 结构化证据融合，全链路逻辑闭环，各组件均围绕"高阶多模态关联"这个核心命题展开。
- **锚点驱动细化机制有启发性**："高频跨页实体 → 星扩展子图 → 仅重建局部拓扑"的三步式设计，将细化从 O(全文) 降为 O(锚点邻域)，思路清晰且具有通用借鉴价值。
- **效率与性能兼顾**：不仅提升了检索/生成质量，还显著降低了 Token 开销，对长文档场景实用性强。
- **评估设计相对严谨**：双响应交换与平均策略缓解位置偏差；跨模型裁判审计确保结论不依赖单一评估器。
- **消融与结构分析互为印证**：不仅报告了性能数据，还从超边数量分布的角度提供了机制层面的解释证据，深化了实验的说服力。

### 8. 不足与局限

- **基准覆盖不够广**：多模态 Global QA 仅用两个自建评估集（教科书、幻灯片），虽无法从公开基准直接选取，但需更多样化领域（如医学影像报告、工程图纸、财务报表）的外部验证。Local QA 仅选用 RealMMBench 两个子集，未覆盖该基准的全部领域。
- **依赖 LLM 抽取质量**：超图构建高度依赖 LLM 的实体抽取和关系识别能力。如果 LLM 在多模态信息融合时产生幻觉或遗漏，错误会沿管道累积，且超图放大效应可能使问题更严重。对真实世界表格、公式密集的极端复杂页面未见鲁棒性分析。
- **评估偏差风险**：Global QA 的 125 个问题全部由 LLM 合成（虽设了多模态依赖约束），真实分布未知。LLM 评判虽做了双向交换与一致性仲裁，仍非人类评估的黄金标准。
