## 摘要
视觉-语言模型（VLMs）展现出强大的零样本能力，使其成为跨多样任务持续学习的吸引性解决方案。然而，在持续适应过程中，灾难性遗忘和零样本能力退化同时发生，严重损害性能。在本文中，我们引入TASSO，一种高效保持潜在空间几何结构同时确保网络可塑性的新范式。我们通过两种互补技术实现这一点：子空间学习和几何感知知识蒸馏。具体而言，我们首先学习一系列任务特定的低秩投影器，用于在优化交叉熵之前投影潜在表示。其次，我们采用基于测地线距离的损失函数，从先前任务模型中蒸馏知识，同时有效保持潜在空间几何结构。这些设计选择不仅避免了沿全嵌入维度的不必要参数更新，还通过聚焦于任务特定流形而改进学习。此外，几何感知蒸馏提供了强正则化，并在整个持续学习序列中显著减少了灾难性遗忘和零样本退化。在CLIP视觉语言模型的多领域任务增量学习和类增量学习基准上的实验结果表明，在缓解遗忘和保持零样本能力方面，该方法明显优于现有最先进方法。

## Abstract
Vision-Language Models (VLMs) exhibit strong zero-shot capabilities, making them an attractive solution for continual learning across diverse tasks. However, during continual adaptation, both catastrophic forgetting and zero-shot degradation occur, severely degrading performance. In this paper, we introduce TASSO, a new paradigm that efficiently preserves the latent space geometry while ensuring network plasticity. We achieve this with two complementary techniques: subspace learning and geometry-aware knowledge distillation. Specifically, we first learn a sequence of task-specific low-rank projectors, which we use to project the latent representations before optimizing cross-entropy. Secondly, we employ a geodesic-distance-based loss that distills knowledge from the previous-task model while effectively preserving the latent space geometry. These design choices not only avoid unnecessary parameter updates along the full embedding dimensions but also improve learning by focusing on task-specific manifolds. Moreover, the geometry-aware distillation provides strong regularization and significantly reduces both catastrophic forgetting and zero-shot degradation throughout the continual learning sequence. Experimental results with the CLIP vision language model in the multi-domain task incremental and class incremental learning benchmarks demonstrate clear improvements over state-of-the-art methods in mitigating forgetting and preserving zero-shot capabilities.

# TASSO 论文详细中文总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言模型（VLM，如 CLIP、BLIP、ALIGN、Flamingo）在零样本分类、多模态理解方面表现卓越，但在实际部署（如具身智能、自动驾驶、机器人）中，静态的通用知识往往不足以应对持续出现的、任务特定的新概念。
- **核心问题**：将 VLM 用于持续学习（Continual Learning）时存在双重退化挑战：
  1. **灾难性遗忘（Catastrophic Forgetting）**：优化新任务导致旧任务性能下降；
  2. **零样本退化（Zero-Shot Degradation）**：学习新任务会损害模型在未来未见任务上的零样本泛化能力——这是 VLM 场景特有的问题。
- **深层矛盾**：需要同时满足"新任务可塑性（plasticity）"与"旧知识/通用知识稳定性（stability）"，这一平衡在 VLM 上比传统 CL 更加困难。
- **现有方法的不足**：
  - 基于蒸馏的方法（如 ZSCL、SnD）需要双教师（预训练模型 + 上一任务模型）或大量参考数据，计算与存储开销大，且可能压制新任务学习能力；
  - 基于参数高效适配的方法（LoRA、MoE-Adapters）虽灵活，但大多未显式地恢复模型可塑性，也较少利用特征子空间中的任务特定结构。

## 2. 方法论：TASSO（TAsk-Specific Subspace Optimization）

### 核心思想
将"新任务优化"约束在低秩子空间内进行，同时用**测地线距离**（geodesic distance）作为知识蒸馏度量，以尊重 CLIP 潜在空间位于高维球面的几何结构，从而兼顾可塑性与稳定性。

### 关键技术细节

**（1）子空间学习（Subspace Learning for Plasticity Restoration）**
- 每个任务 k 学习一个低秩投影器 U_k ∈ R^(d×r)，r ≪ d（实验 r=144）；
- 通过 QR 分解重参数化保证 U_k 的列正交（U_k^T U_k = I）；
- 将嵌入分解为：
  - 任务特定子空间：f_∥ = U_k U_k^T f；
  - 任务无关子空间：f_⊥ = f − f_∥；
- 在子空间内计算 softmax 概率并应用交叉熵损失，**投影器仅在训练时使用**，推理时移除，便于 MTIL 与 MCIL 两种设定无缝切换；
- 子空间损失：L_sub = CE(softmax(⟨U_kU_k^T f_i, U_kU_k^T f_t(c)⟩), y)。

**（2）几何感知知识蒸馏（Geodesic Distance for Stability）**
- 关键洞见：CLIP 的嵌入经过归一化，位于高维球面上，L2/余弦距离沿"弦"测量，不符合流形固有几何；测地线距离（cos⁻¹⟨·,·⟩）沿球面测地线测量更合适；
- 蒸馏损失：在任务特定与任务无关两个子空间上分别计算测地线距离并求和：
  L_KD = (1/N) Σ [cos⁻¹(f^∥_k, f^∥_{k−1}) + cos⁻¹(f^⊥_k, f^⊥_{k−1})]；
- 相比直接在原始向量上计算，子空间分解后的蒸馏能显著改善遗忘与零样本退化（补充实验显示 CF 改善 33%、ZS 改善 39%）。

**（3）总目标函数**
L = L_CE + α·L_sub + β·L_KD
- 超参数：α = 0.5，β = 3。

**（4）与其他方法的关键差异**
- 仅需**一个教师模型**（上一任务模型 g^{k−1}），无需双教师（对比 SnD）；
- 不显式增加 adapter 模块；
- 仅在训练时使用低秩投影，推理零额外参数。

## 3. 实验设计

### 基准与数据集
- 模型：CLIP（open_clip 实现），视觉编码器 ViT-B/16，文本编码器冻结；
- 8 个细粒度分类数据集（共 694 类）：
  FGVC-Aircraft、DTD、EuroSAT、Flowers-102、Food-101、Oxford-Pets、Stanford-Cars、UCF-101；
- 两种评估设置：
  - **MTIL**（多域任务增量学习）：推理时已知任务索引；
  - **MCIL**（多域类增量学习）：推理时任务未知，在所有 694 类中进行分类（更具挑战）；
- **任务顺序鲁棒性**：不同于以往只用 1~2 个固定顺序，构造了 8 个旋转顺序 S1~S8，降低顺序偏差；
- 蒸馏参考数据集：ImageNet 中 100K 无标注图片（与 ZSCL、SnD 保持一致）。

### 评估指标
1. **Accuracy**：所有任务训练完成后的平均准确率；
2. **Catastrophic Forgetting**：之前任务上的平均最大性能下降；
3. **Zero-Shot Degradation**：未见任务上相比预训练模型的最大性能下降。

### 对比方法
- 基础基线：Continual FT（朴素微调）；
- 经典 CL 方法：LwF、iCaRL；
- 最新 SOTA：ZSCL、MoE-Adapters、GIFT、SnD。

## 4. 资源与算力

- GPU：NVIDIA RTX 4090 单卡；
- 全部 8 个数据集训练一轮约 **96 分钟**（1 小时 36 分 0 秒）；
- 计算量：S1 完整训练（80k 迭代）TASSO 为 **13.34 TFLOPs**（略低于 SnD 的 15.49 TFLOPs）；
- 最大显存占用：约 **17.13 GB**；

### 主要实验

### 充分性评价
- **全面且客观**：8 个任务顺序消除顺序偏差；多组消融定位各组件贡献；多种子实验确认稳定性；与最接近的 SOTA（SnD）进行了计算开销、显存、训练时间的直接对比；
- **公平性良好**：蒸馏参考数据集与先前方法保持一致（100K ImageNet）；种子设置也刻意对齐（seed 1102 与 SnD 相同）。

## 6. 主要结论与发现

1. **准确率显著领先**：MTIL 平均准确率 85.89%（较最佳基线 SnD 高约 1%）；MCIL 平均 85.15%（高约 1.4%），在全部 8 个顺序上均为最优；
2. **灾难性遗忘大幅抑制**：MTIL 平均遗忘仅 0.67%（SnD 为 1.20%）；MCIL 平均 0.86%（SnD 为 1.35%）；
3. **零样本退化几乎消除**：MTIL 平均仅 0.47%，MCIL 平均 0.63%，约为最接近基线的 1/3 到 1/4，是所有指标中相对提升最大的；
4. **两种技术互补**：子空间学习提升可塑性与准确率，测地线蒸馏强化稳定性，二者结合效果最优；
5. **多模态对齐改善**：TASSO 在 7/8 个数据集上显著降低了文本-视觉嵌入间距，表明蒸馏维持了 CLIP 的模态对齐结构；
6. **任务顺序稳健**：所有指标在 S1~S8 不同顺序下保持高度一致，说明方法对顺序不敏感。

## 7. 优点

- **方法论层面**：
  - 仅用单教师模型即可同时解决灾难性遗忘与零样本退化，比双教师蒸馏（SnD）更高效；
  - "低秩子空间内学习 + 子空间分解蒸馏"的分离策略兼顾可塑性与稳定性，直观且优雅；
  - 引入测地线距离，与 CLIP 归一化嵌入的球面流形几何天然契合，理论动机清晰；
  - 投影器仅在训练期使用，推理时无额外参数与计算负担；
  - 超参数敏感度低（r、α、β 在较大范围内性能稳定），实用性强；
  - 计算开销低于主竞品 SnD（TFLOPs 更低、训练更快）。
- **实验设计层面**：
  - 使用 8 个旋转任务顺序而非固定顺序，是评估 VLM 持续学习中少见的严谨做法；
  - 消融设计系统、覆盖全面（组件、超参、优化策略、距离函数、多种子统计），结论可信度高。

## 8. 不足与局限

- **模型泛化范围有限**：仅验证了 CLIP + ViT-B/16 一种架构，未测试其他 VLM（BLIP、ALIGN 等）或其他骨干（ViT-L、ViT-H）；
- **任务类型单一**：仅限图像分类任务，未涉及检测、分割、VQA 等更广泛的下游任务；
- **仅适配视觉分支**：文本编码器全程冻结，作者也承认模态间对齐是未来工作方向；
- **固定秩设计**：r=144 对所有任务一刀切，未根据任务语义复杂度动态调整（作者在 Future Work 中已指出）；
- **依赖外部参考数据集**：需要 ImageNet 100K 无标注图片用于蒸馏，在无此类参考数据的场景中应用受限；
- **数据集覆盖面有限**：8 个数据集均为自然图像/纹理/卫星等视觉域，未涉及更广泛的多模态或开放域场景；
- **消融研究仅在单一顺序（S1）上报告**（主文部分），虽然补充材料补了 MCIL 消融，但更完整的顺序×消融交叉验证仍有提升空间；
- **潜在偏差风险**：作者观察到 DTD 数据集排在序列首位时性能最佳、排在末位时最差，说明任务间信息迁移存在不对称性，方法虽降低了顺序敏感性但未完全消除。
