## 摘要
基于知识的视觉问答（KB-VQA）旨在回答需要超越视觉内容、对外部知识源进行推理的查询。通常，现有方法融合多模态特征以检索外部信息，随后利用多模态大语言模型（MLLMs）从检索到的证据中推导答案。然而，这些方法往往难以捕捉复杂上下文中的结构关联，无法有效过滤噪声，且常无法确保推理过程严格忠于检索到的证据。针对这些挑战，我们提出了SAFE-G，一种结构感知的忠实证据引导生成框架，能够实现精准的证据定位和可信推理。具体而言，我们首先采用融合视觉与文本模态的粗粒度混合搜索来召回候选文档，随后实施结构感知的细粒度图检索，以捕捉结构依赖关系并过滤噪声、精确定位证据。此外，我们引入了一种带有证据接地奖励的强化学习（RL）策略，仅当所选证据正确时才为正确答案赋予奖励。这种严格的对齐约束迫使模型将回答锚定在检索上下文中，有效增强其通过多模态特征定位证据并进行忠实推理的能力。在Encyclopedic-VQA和InfoSeek基准上的大量实验表明，SAFE-G分别以8.9%和3.5%的优势超越先前方法，显著提升了整体推理精度。我们的源代码已公开：https://github.com/MINE-USTC/SAFE-G

## Abstract
Knowledge-based Visual Question Answering (KB-VQA) aims to answer queries that necessitate reasoning over external knowledge sources beyond the visual content. Typically, current methods fuse multimodal features to retrieve external information, subsequently leveraging Multimodal Large Language Models (MLLMs) to derive answers from the retrieved evidence. However, these methods often struggle to capture structural associations within complex contexts to effectively filter noise. Furthermore, they frequently fail to ensure that the reasoning process remains strictly faithful to the retrieved evidence. To address these challenges, we propose SAFE-G, a Structure-Aware Faithful Evidence-guided Generation framework, which enables precise evidence localization and trustworthy reasoning. Specifically, we first employ a coarse-grained hybrid search fusing visual and textual modalities to recall candidate documents, and subsequently implement a structure-aware fine-grained graph retrieval that captures structural dependencies to filter noise and pinpoint precise evidence. Moreover, we introduce a reinforcement learning (RL) strategy with an evidence-grounded reward that assigns credit to correct answers only when the selected evidence is correct. This strict alignment constraint compels the model to anchor its response in the retrieved context, effectively enhancing its capability to locate evidence via multimodal features and perform faithful reasoning. Extensive experiments on the Encyclopedic-VQA and InfoSeek benchmarks demonstrate that SAFE-G outperforms prior methods by a margin of 8.9% and 3.5%, substantially enhancing the overall reasoning accuracy. Our source code is publicly available at: https://github.com/MINE-USTC/SAFE-G.

### 2. 论文提出的方法论

SAFE-G 是一个三阶段框架，整体思想是“粗检索 → 图精排 → 强化学习对齐”。

#### 阶段一：粗粒度多模态混合检索
- **目的**：在百万级文档库中快速筛出与查询图像相关的候选文档集 \( C_q \)。
- **关键步骤**：
  - 用预训练摘要模型为每篇文档生成**摘要**（summary），压缩文档核心语义。
  - 使用 CLIP 编码器将查询图像与文档摘要、文档图像分别计算相似度，并通过加权融合得到文档级相关分数：
    \[
    Score_{d_i} = \alpha \cdot \text{sim}(E_v(I_q), E_t(m_i)) + (1-\alpha) \cdot \text{sim}(E_v(I_q), E_v(I_i))
    \]
  - 用 FAISS 进行最大内积搜索，取 Top-K 文档进入下一阶段。

#### 阶段二：结构感知细粒度图检索
- **目的**：在候选文档内定位具体证据片段（section），并过滤噪声。
- **关键步骤**：
  - 利用 OpenIE 抽取文档中所有段落的**三元组** (head, relation, tail)，构建无模式异构知识图：节点为“段落节点”和“实体节点”，边为包含（contain）和关系（relation）边。
  - **多模态先验注入**：将阶段一的文档级多模态分数经 min-max 归一化后，与文本密集检索分数（DPR）相乘，形成段落节点的初始化权重：
    \[
    w_{i,j} = \text{DPR}(s_{i,j}) \cdot (1 + \beta \cdot \tilde{\rho}_i)
    \]
    实体节点也通过查询与三元组的相似度进行激活，作为辅助语义种子。
  - **查询个性化传播**：以多模态先验作为 Personalized PageRank（PPR）的个性化向量，在图中传播相关性分数，汇聚跨段落的结构线索，最终按稳态分布取 Top-K 段落作为证据集 \( E_q \)。
- **设计亮点**：全程**无需训练重排序器**，仅靠图传播完成证据精排。

#### 阶段三：证据引导生成（强化学习）
- **目的**：强制 MLLM 在推理过程中忠实引用检索到的证据，抑制幻觉。
- **输出格式约束**：要求模型生成结构化输出：`<think>`（推理过程）、`<evidence>`（引用内容）、`<answer>`（最终答案）。
- **Reward 设计**（证据接地奖励）：
  - **格式奖励** \( r_{fmt} \)：输出格式合规为 1，否则为 -1。
  - **章节奖励** \( r_{sec} \)：引用的文档标题与真实支持文档标题一致为 1，否则为 0。
  - **准确性奖励** \( r_{acc} \)：答案正确 **且** 章节奖励为 1 时才得 1，否则为 0（即“证据门控”）。
  - **总奖励（级联评估）**：
    \[
    r(o_i) = \begin{cases} -1 & \text{if } r_{fmt} = -1 \\ r_{fmt} + r_{sec} + r_{acc} & \text{if } r_{fmt} = 1 \end{cases}
    \]
- **训练算法**：采用 GRPO（Group Relative Policy Optimization）进行策略优化，无需价值函数网络，按组内相对优势更新策略参数，通过 LoRA 参数高效微调。

### 6. 论文的主要结论与发现

- **性能提升显著**：
  - E-VQA：SAFE-G（Qwen2.5-VL-7B）达到 **45.1%**，较先前 SOTA（CC-VQA 41.4%）高 3.7 点，较 VLM-PRF（37.1%）高 8.0 点。
  - InfoSeek：SAFE-G 达 **46.7%**，较 CC-VQA 高 1.6 点，较 VLM-PRF 高 3.9 点。
  - 3B 模型（39.2%）甚至超越 VLM-PRF-7B（37.1%），证明证据监督能补偿模型容量不足。
- **检索端不再依赖训练重排序**：SAFE-G 的 PPR 图传播在 Section Recall 上达到与训练后的 EchoSight 相当的水平（R@1 约 0.253 vs 0.243），表明图结构传播可以替代昂贵的监督训练。
- **证据门控奖励是提升关键**：消除证据门控后 E-VQA 从 43.2% 掉到 38.3%（-4.9），说明“只有正确证据 + 正确答案才给奖励”是抑制幻觉的核心。
- **RL > SFT > Zero-shot**：相同检索证据下，GRPO 训练（45.1%）显著优于 SFT（40.4%）和零样本（34.8%），说明 RL 能探索出比静态标注更优的推理策略。
- **样本效率高**：4K 训练数据已接近性能上限（5K-6K 收益递减），RL 训练的是“证据定位与利用能力”而非记忆样本模式。
- **多模态先验驱动证据定位**：移除图像引导的节点初始化后性能下降约 2.4 点，验证视觉-语义一致性在 KB-VQA 证据定位中的关键作用。
