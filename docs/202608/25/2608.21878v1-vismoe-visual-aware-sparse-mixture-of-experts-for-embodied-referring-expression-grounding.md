## 摘要
具身指代表达定位是指使智能体能够在真实环境中导航并根据自然语言指令定位远处物体的任务。在此场景中，智能体需要在每一步选择一个视图用于导航，并在目的地从所有候选物体中识别出特定物体。然而，以往的大多数方法未能区分视图和物体，而是使用普通的视觉编码器对它们进行处理，导致视图和物体的表示都产生歧义。为了解决上述问题，我们提出了ViSMoE，它为具身智能体配备了具有视觉感知路由策略的稀疏专家混合模型。该框架专门处理不同类型的视觉信息，从而为视图和物体生成具有判别性的视觉表示。在REVERIE和SOON数据集上的实验结果表明，ViSMoE优于先前的最先进方法，展示了我们提出的方法的优越性。

## Abstract
Embodied Referring Expression Grounding is the task of enabling an agent to navigate in real environments and to localize a remote object based on natural language instructions. In this scenario, the agent needs to select one view for navigation at each step and identify a specific object among all candidate objects at the destination. However, most of the previous approaches fail to distinguish between views and objects, instead processing them using the vanilla vision encoder, which results in ambiguous representations of both views and objects. To address the above issues, we propose ViSMoE, which equips sparse Mixture-of-Experts with a visual-aware routing policy for the embodied agent. This framework processes different types of visual information specifically, resulting in discriminative visual representations for both views and objects. Experimental results on REVERIE and SOON datasets demonstrate that ViSMoE outperforms the previous state-of-the-art methods, showing the superiority of our proposed method.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定义**：具身指代表达定位要求智能体在真实室内环境中，根据高层级自然语言指令逐步导航（每步选择一个离散视角），并在到达目的地后从候选物体中定位目标物体。该任务涵盖视觉-语言导航（VLN）与指代表达定位（REG）两个子任务，以 REVERIE 和 SOON 数据集为典型基准。
- **现有方法的缺陷**：以往方法（如 DUET）将离散视图（对房间布局的全局概览）和候选物体（对具体物品的局部细节）不加区分地拼接后输入同一视觉编码器。这种做法忽略了二者在**数据分布**和**承担任务**上的本质差异：
  - 视图服务于语言引导的导航决策（时序性、空间布局）；
  - 物体服务于到达目的地后的指代定位（细节性、类别判别）。
- **核心研究问题**：如何在统一框架下，对分布不同、任务不同的两类视觉输入进行判别性建模，而不是“一刀切”地使用同一个 FFN 处理。
- **论文的总体含义**：提出将稀疏专家混合模型引入视觉编码，通过视觉感知的路由策略让不同类型的视觉 token 自动分流至特定专家，从而获得更精准的视图表示与物体表示，最终提升导航与定位的整体性能。

## 2. 方法论（核心思想、技术细节与流程）

- **总体框架**：以 DUET 为基础模型，包含语言编码器、视觉编码器（全景编码器）、双尺度跨模态编码器，分别负责：
  - 语言 token 的上下文编码；
  - 视图与物体的视觉编码；
  - 局部（视图/物体与语言交叉注意力）与全局（图节点与语言交叉注意力）推理。
- **核心创新：ViSMoE 层**
  - **稀疏专家混合模型（SMoE）**：在视觉编码器的 FFN 位置替换为 SMoE 层。每个 SMoE 层包含一个门控网络和 N 个专家 FFN。给定输入 token x，路由计算为：
    - \(G(x) = \text{top-k}(\text{softmax}(W_g \cdot x))\)
    - 输出为所选 k 个专家输出的加权和：\(\hat{x} = \sum_{i=1}^{k} G(x)_i \cdot \text{FFN}_i(x)\)
  - **视觉感知路由策略（Visual-Aware Routing）**：这是论文的核心贡献。与标准 SMoE 不同，ViSMoE 在路由网络的输入中加入**可学习的视觉类型嵌入**，以显式告知路由器当前 token 是“视图”还是“物体”：
    - \(G(x) = \text{top-k}(\text{softmax}(W_g \cdot (x + b_t)))\)
    - 其中 \(b_v\) 用于视图表示 V，\(b_o\) 用于物体表示 O。
    - 效果：标准 SMoE 会把不同类型视觉 token 均匀分散到所有专家；ViSMoE 则学会将视图 token 路由到部分专家、物体 token 路由到另一部分专家，实现专家分化。
  - **负载均衡辅助损失**：采用 Switch Transformer / Shazeer 等人的 auxiliary loss，防止 token 路由失衡：
    - \(L_{\text{Aux}} = \alpha \cdot N \sum_{i=1}^{N} p_i \times f_i\)，\(\alpha = 0.001\)。
- **训练流程**：
  - **预训练**阶段：MLM（掩码语言建模）+ MRC（掩码区域分类）+ SAP（单步动作预测）+ OG（物体定位）+ Aux 损失。
  - **微调**阶段：SAP + DAgger（模仿学习，基于采样轨迹修正偏差）+ OG + Aux 损失。
  - ViSMoE 层插入位置：全景编码器（Pano.2）以及局部跨模态编码器的全部 4 层。
