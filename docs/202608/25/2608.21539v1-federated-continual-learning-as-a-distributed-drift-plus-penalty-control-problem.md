## 摘要
联邦持续学习（FCL）是现实世界分布式学习系统的基础，要求模型适应客户端间顺序、非独立同分布的数据，同时减轻灾难性遗忘和客户端漂移。现有方法将持续学习（CL）表述为一系列每任务优化问题，在每个客户端本地应用并通过聚合耦合，使用诸如重放、正则化或基于投影的约束等启发式机制。然而，FCL中的遗忘本质上是一种长期、分布式的现象，源于时间任务演化与跨客户端异质性的相互作用，并未得到显式调节。在这项工作中，我们将FCL视为一个随机控制问题，并提出联邦队列调节持续学习（FedQCL），一种基于李雅普诺夫漂移加罚（DPP）优化的框架。FedQCL引入虚拟队列来跟踪跨任务和客户端的遗忘累积，从而实现对稳定性-可塑性权衡的显式控制。通过优化DPP目标，该方法在提升当前任务性能的同时，基于队列的公式提供了一种可解释且可调的机制，通过单一参数平衡适应与保留，无需梯度投影或额外通信开销。在标准基准测试（包括Split-CIFAR-10、Split-CIFAR-100和Split-TinyImageNet）上的实证评估表明，FedQCL在异构数据分布下，在准确性方面优于最先进的基线，同时显著减少遗忘。

## Abstract
Federated Continual Learning (FCL) is fundamental to real-world distributed learning systems, requiring models to adapt to sequential, non-IID data across clients while mitigating catastrophic forgetting and client drift. Existing approaches formulate continual learning (CL) as a sequence of per-task optimization problems, applied locally at each client and coupled through aggregation, using heuristic mechanisms such as replay, regularization, or projection-based constraints. However, forgetting in FCL is inherently a long-term, distributed phenomenon, arising from the interaction of temporal task evolution and cross-client heterogeneity, which is not explicitly regulated. In this work, we cast FCL as a stochastic control problem and propose Federated Queue-regulated Continual Learning (FedQCL), a framework based on Lyapunov drift-plus-penalty (DPP) optimization. FedQCL introduces virtual queues to track the accumulation of forgetting across tasks and clients, enabling explicit control of the stability-plasticity trade-off. By optimizing a DPP objective, the method jointly improves current-task performance while the queue-based formulation provides an interpretable and tunable mechanism to balance adaptation and retention through a single parameter, without requiring gradient projection or additional communication overhead. Empirical evaluations on standard benchmarks, including Split-CIFAR-10, Split-CIFAR-100, and Split-TinyImageNet, demonstrate that FedQCL outperforms state-of-the-art baselines with respect to accuracy while significantly reducing forgetting under heterogeneous data distributions.

## 1. 核心问题与研究动机

**问题背景：**
- 联邦持续学习（FCL）是现实分布式系统（如移动设备、可穿戴设备）中模型训练的关键范式，要求模型在多个客户端上处理**顺序到达的非IID数据**，同时适应新任务并保留旧任务知识。
- 核心挑战是**灾难性遗忘**（catastrophic forgetting）——模型在学习新任务时迅速丧失旧知识。这一问题在联邦环境中因**客户端数据异质性**（non-IID）而进一步加剧，引发客户端漂移（client drift）与全局学习动力学的不稳定。

**现有方法的不足：**
- 现有FCL方法（重放、正则化、梯度投影等）均将持续学习视为**逐任务的局部优化问题**，通过启发式机制（如重放缓冲、参数约束）缓解遗忘。
- 这些方法均采用**短视的、逐轮优化**策略，未显式建模遗忘在时间维度和跨客户端维度上的**长期累积效应**——遗忘本质上是动态、分布式、跨任务交互产生的结果，而非单一时间点的静态现象。

**核心立意：**
- 作者主张将FCL重新概念化为一个**受约束的随机控制问题**，而非单纯的每轮优化问题，从而将遗忘视为可调控的长期约束违规累积过程，实现稳定性-可塑性权衡的**显式、可解释**管理。

## 2. 方法论：FedQCL

**核心思想：**
- 基于**李雅普诺夫漂移加罚（Drift-Plus-Penalty, DPP）**优化框架，将遗忘约束转化为**虚拟队列**的稳定性控制问题。
- 目标是：在最小化当前任务损失（塑性）的同时，通过队列状态约束遗忘累积（稳定性）。

**关键技术细节：**

- **问题建模**：全局目标为最小化跨任务平均损失，同时约束平均遗忘不超过容忍阈值δ（公式3）。

- **虚拟队列更新**（公式4）：

  Q⁽ᵏ⁾ᵢ[t] = max{ Q⁽ᵏ⁾ᵢ[t−1] + [Φ̂⁽ᵏ⁾ᵢ(w⁽ᵗ⁾ᵢ) − Φ̂⁽ᵏ⁾ᵢ(w⁽ᵗ⁻¹⁾) − δ], 0 }

  其中Q⁽ᵏ⁾ᵢ[t]是客户端i上过去任务k的虚拟队列值，Φ̂为基于本地重放缓冲区的回放损失。队列值越大，表示遗忘累积越严重。

- **局部DPP目标**（公式6、9）：

  DPP⁽ᵗ⁾ᵥ,ᵢ = V·Φᵢ(w; D⁽ᵗ⁾ᵢ) + Σₖ Q⁽ᵏ⁾ᵢ[t−1]·ΔΦ̂⁽ᵏ⁾ᵢ(w, w⁽ᵗ⁻¹⁾)

  - 第一项：当前任务损失，由参数V缩放，控制塑性。
  - 第二项：队列加权的遗忘惩罚项，控制稳定性。
  - **V为单一控制参数**，实现稳定性-塑性的可调平衡。

- **Lemma 1**：给出了李雅普诺夫漂移的上界，将漂移分解为遗忘的二次项和由虚拟队列加权的线性项，为省略二次项提供了理论依据。

- **算法流程（Algorithm 1）**：
  1. 初始化全局模型w⁽⁰⁾，队列Q=0，参数V、δ。
  2. 对每个任务t，执行C轮通信：
     - 服务器广播全局模型w⁽ᵗ,ᶜ⁻¹⁾。
     - 每个客户端并行执行R步局部SGD：梯度由V·当前任务梯度 + Σₖ Q⁽ᵏ⁾ᵢ[t−1]·回放梯度组成（公式10）。
     - 客户端在每轮通信后**更新本地队列**（而非仅在任务边界更新），实现细粒度的遗忘跟踪。
     - 服务器进行FedAvg加权聚合。
  3. 队列在通信轮级别更新而非任务级别——这是关键设计选择，因为遗忘在通信轮内随迭代更新持续演化。

- **通信效率**：队列完全保存在本地，**零额外通信开销**；无梯度投影或SVD等服务器端额外计算。
