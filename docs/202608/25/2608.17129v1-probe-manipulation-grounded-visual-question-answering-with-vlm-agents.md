## 摘要
视觉语言模型（VLM）在静态场景中的二维接地、空间推理和基于工具的智能体规划方面表现出色。然而，考虑询问家用机器人“我的药还在柜子里吗？”答案可能物理上隐藏在一排容器后面，必须先将它们移开。在真实世界杂乱环境中回答此类问题需要在动态场景中进行推理：必须操纵干扰物以揭示被遮挡的物体，并且每个动作都会改变模型必须推理的场景。我们将这一设置形式化为基于操作落地的视觉问答（MG-VQA），并引入PROBE，一个用于在此类任务上对VLM智能体进行基准测试和微调的框架。我们首先开发了PROBE-Sim，一个具有日常物体和配备抓取和推动工具机器人操纵器的高保真桌面模拟器。PROBE-Sim用于创建PROBE-Bench：一个包含6种问题类型、150个杂乱桌面场景任务的评估套件，其中VLM在回答之前感知、拾取或推动物体。我们观察到所有前沿VLM的一致趋势：基于智能体工具的方法在几乎所有任务类型上都优于其仅感知的基线（平均提高8.0%）。我们进一步设计了PROBE-Agent，一种微调方法，通过混合数据策略从强大的教师基础模型提炼成功轨迹到较小的开源权重模型，以鼓励操作高效的视觉问答。经过PROBE-Agent微调的模型优于其现成的智能体基线（平均提高11.5%），并展示了对未见物体和保留任务的正面迁移。我们通过在真实桌面环境中部署PROBE-Agent微调策略来验证从模拟到真实的迁移。

## Abstract
Vision-language Models (VLMs) excel at 2D grounding, spatial reasoning and agentic tool-based planning in static scenes. However, consider asking a home robot "Is my medication still in the cabinet?" The answer may be physically hidden behind a row of containers that must first be moved aside. Answering such questions in real-world cluttered environments requires reasoning in dynamic scenes: distractors must be manipulated to reveal occluded objects, and each action changes the scene the model must reason over. We formalize this setting as Manipulation-Grounded Visual Question Answering (MG-VQA) and introduce PROBE, a framework for benchmarking and finetuning VLM agents on such tasks. We first develop PROBE-Sim, a high-fidelity tabletop simulator with everyday objects and a robot manipulator equipped with grasping and pushing tools. PROBE-Sim is used to create PROBE-Bench: an evaluation suite of 150 tasks across 6 question types on cluttered tabletop scenes, where a VLM perceives, picks up or pushes objects before answering. We observe consistent trend across all frontier VLMs: agentic tool-based methods outperform their perception-only baselines (8.0% on average) across all task types. We further design PROBE-Agent, a finetuning recipe to distill successful trajectories from a powerful teacher foundation model to a smaller open-weight model using a mixed data recipe that encourages manipulation-efficient question answering. PROBE Agent finetuned models outperform their off-the-shelf agent baseline (11.5% on average) and demonstrate positive transfer to unseen objects and a held-out task. We validate sim-to-real transfer by deploying PROBE-Agent finetuned policies in real-world tabletop environments.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有 VLM 在静态场景中表现优秀，但真实世界中的问题往往需要物理交互才能回答。例如“我的药还在柜子里吗？”——药瓶可能被其他容器遮挡，必须先移开障碍物才能看到。这类任务要求 VLM 在**动态变化场景**中进行推理：每一次操作都会改变模型需要推理的场景内容。
- **核心问题**：现有评估基准（如传统 VQA、Embodied QA）几乎都假设答案可从单张静态图像中获得，忽略了物理交互的必要性。本文提出**Manipulation-Grounded VQA (MG-VQA)** 任务形式，研究 VLM 智能体如何通过“感知-操作-再感知-回答”的闭环流程来回答涉及物体遮挡的问题。
- **整体含义**：这是首个将**VLM 智能体工具使用**与**操作落地 VQA** 结合的基准与微调框架。它推动了从“看图回答”到“动手探索后回答”的范式转变，对家用机器人、服务机器人的视觉推理能力评估具有重要意义。

## 2. 论文提出的方法论

### 2.1 核心思想
构建一个统一的框架，包含仿真环境、评测基准和微调配方三个部分（即 PROBE-Sim、PROBE-Bench、PROBE-Agent），使 VLM 智能体能够在杂乱桌面环境中通过调用感知和操作工具，收集必要证据后回答问题。

### 2.2 PROBE-Sim（仿真环境）
- **物理引擎**：PyBullet，模拟重力、摩擦、接触、抓取和推动动力学。
- **渲染器**：Blender-EEVEE，为 VLM 生成 1024×1024 顶视角 RGB 图像。
- **资产**：1,796 个真实扫描的日常物体（来自 Megapose、Digital Twin Catalogue、BOP Challenge），涵盖 481 个类别。所有物体均用 VLM 辅助标注并人工审查，确保名称、颜色、类别描述的明确性。
- **机器人**：UR5 + Robotiq 2F-140 末端夹爪，支持 6-DOF 抓取和闭夹推动。
- **场景生成**：随机采样 108 种桌面纹理，在 50×50cm 紧凑区域内生成 15 个物体，经 30 秒物理稳定后作为初始场景。
- **工具集（Toolshed）**：5 种工具——`perceive scene`（场景图）、`find object`（2D 定位+掩码）、`grasp and remove`（6-DOF 抓取并移除物体）、`push`（闭夹线性推动）、以及回答工具。工具具有**非确定性噪声**（抓取可能失败、分割不精确等），模拟真实操作的不确定性。

### 2.3 PROBE-Bench（评测基准）
- **任务规模**：150 个人工验证过的任务，由算法生成，保证可扩展性和 ground truth 明确性。
- **6 种问题类型**：
  - **Count**：统计目标物体数量（需清理遮挡后计数）
  - **Find**：定位目标物体的 2D 点
  - **Compare**：比较两个匿名物体（通过 2D 点指示）的颜色属性
  - **Size**：比较两个匿名物体的尺寸属性
  - **Reduce**：移除指定数量的物体（强制操作任务，作为操作成本对照）
  - **Beneath**：识别指定遮挡物下方的物体（最难的遮挡推理任务）
- **答案形式**：多项选择（Find 还需输出 2D 定位点）。
- **人工验证**：人类专家在相同工具和噪声条件下逐任务验证，确保每个任务无歧义且可解，确立 100% 的性能上界。

### 2.4 PROBE-Agent（微调配方）
- **思想**：从强教师模型（Gemini 3.1 Pro）在 PROBE-Sim 中运行产生的成功轨迹中蒸馏知识到小型开源模型。
- **训练数据**：2,947 条轨迹，包含直接回答和智能体操作两种模式的成功示例，分布在 5 种训练任务上（Beneath 被保留用于测试泛化）。训练场景使用与评测不重叠的 1,437 个物体资产。
- **训练细节**：对 Qwen3-VL-8B 和 NVILA-15B 两个基座模型进行监督微调，学习率 2e-5，batch size 32，2 个 epoch。
- **设计意图**：混合数据配方让模型学会**何时操作、何时直接回答**——即操作效率最高的决策策略，而不仅仅是学会调用工具。

## 3. 实验设计

### 3.1 评测场景与基准
- **PROBE-Bench**：150 个任务（Count 21 个、Find 28 个、Compare 24 个、Size 28 个、Reduce 23 个、Beneath 26 个），全部经人工验证。
- **每个任务**：初始 RGB 图像 + 问题 → 模型可以选择直接回答或调用工具进行操作 → 最终给出答案。每个模型在每任务上运行 3 次取成功率。

### 3.2 对比模型
- **专有模型（5 个）**：Gemini 3.1 Pro、Gemini Robotics ER 1.6、GPT-5.4、Opus 4.7、Grok 4.3。
- **开源模型（3 个）**：Nemotron 2-VL-12B、Qwen3.5-VL-235B-A22B、Gemma-4-31B。
- 每个模型在两种模式下评测：**Direct VQA**（仅图像+问题，无工具）和**Agentic VQA**（有工具访问）。
- **微调模型（PROBE-Agent）**：Qwen3-VL-8B-SFT 与 NVILA-15B-SFT，与其未微调的 agentic 基线对比，并以教师模型为参考上界。

### 3.3 真实机器人实验

## 6. 论文的主要结论与发现

- **工具访问普遍提升性能**：所有 8 个评测 VLM 在 Agentic 模式下平均比 Direct 模式高 **8.0%**（CMH 检验 p=5.18×10⁻⁵，统计显著）。
- **弱模型受益更大**：Gemma-4 提升 +16.0%，Opus 4.7 提升 +14.4%，说明工具使用有“均衡器”效应。
- **任务仍未饱和**：最强模型 Gemini 3.1 Pro（Agentic）仅达 69.2%，且 Reduce 任务仅 30.4%，说明操作规划和目标选择仍是瓶颈。
- **工具帮助与场景有关**：当问题明确指示操作目标（Compare、Size）时，工具使用效果好；当模型需要自行判断操作对象（Count、Reduce）时，错误操作会导致错误累积。
- **PROBE-Agent 微调有效**：Qwen3-VL-8B-SFT 从 48.1% 提升至 67.8%，NVILA-15B-SFT 从 51.7% 提升至 69.1%，均达到或超过教师水平（67.6%）；
  - **保留任务泛化**：在未训练的 Beneath 任务上分别提升 +7.6% 和 +15.4%，证明技能的**组合泛化**能力。
- **Sim-to-real 迁移成功**：Qwen3-VL-8B-SFT 在真实机器人上达 70.0%，远高于 base 的 34.4%，接近教师的 78.9%。

## 7. 优点

- **问题设定新颖且实用**：将“操作后回答”形式化为 MG-VQA，填补了静态 VQA 与具身操作之间的空白。
- **高保真仿真环境**：基于真实扫描物体（1,796 个）和成熟的 PyBullet 物理引擎，有助于缩小 sim-to-real 差距。
- **算法化任务生成**：不再依赖人工设计的任务，使基准可扩展到任意规模，并保证 ground truth 可由仿真器精确推导。
- **统一智能体框架**：所有模型共享同一工具集、同一 API、同一评价协议，对比公平。
- **混合数据微调配方**：将“直接回答”和“操作回答”的成功轨迹混合训练，让小型模型学会**决策何时操作**而非仅仅会调用工具。
- **统计严谨**：使用 CMH 检验而非简单的均值比较，增强了结论可靠性。
- **预留任务验证泛化**：将 Beneath 保留出训练集，专门测试组合泛化能力，设计严谨。

## 8. 不足与局限

- **环境范围窄**：仅处理桌面固定机械臂场景，带固定顶视角/前视角相机，未扩展到移动操作、双臂协作或更开放的家居环境。
- **固定工具集不具扩展性**：智能体只能在预定义的 5 种工具中选择，无法在运行时编写新工具或自适应调整策略来恢复失败。
- **操作失败率未被充分利用**：虽然模拟了工具的随机失败，但模型和基准未明确惩罚失败操作（如没有操作次数预算约束的显式建模）。
- **Reduce 任务表现差**：所有模型在 Reduce 上成功率都很低（最高 42.9%），说明“选择哪些物体移除”这一核心决策问题未得到充分解决。
- **人工验证单一性**：仅一名人类专家验证任务，无法量化任务难度的一致性和潜在歧义。
- **微调数据依赖强教师**：蒸馏质量受限于 Gemini 3.1 Pro 的轨迹质量，如果教师策略有系统性缺陷，学生也会继承。
- **真实实验局限**：真实机器人评测任务量少，且未覆盖所有 6 种问题类型，sim-to-real 结论的外推性有限。
- **缺少负面结果分析**：未系统分析工具使用导致性能下降的场景（如 Count/Reduce 中工具调用错误的具体模式）。
