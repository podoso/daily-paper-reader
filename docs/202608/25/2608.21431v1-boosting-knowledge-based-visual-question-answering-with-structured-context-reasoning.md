## 摘要
知识增强的视觉问答旨在通过将外部知识与视觉和文本信息相结合来回答关于图像的问题。近期方法往往依赖上下文学习，以零样本或少样本方式向大型语言模型（LLM）提供多模态上下文。然而，我们观察到，将异构的视觉描述和检索到的知识直接拼接成冗长、非结构化的提示，通常会因过度不相关的上下文以及缺乏显式的关系结构而降低推理性能。在本文中，我们提出了一种基于LLM的结构化上下文推理（SCoRe）框架，该框架推断显式和隐式关系以进行预测。SCoRe包含三个阶段：上下文获取（Context Acquisition），通过高效的两阶段多模态检索策略生成多样的视觉笔记并检索显式知识；上下文选择（Context Selection），利用LLM引导的选择过滤相关的视觉、显式和隐式知识；以及上下文压缩（Context Compression），执行关系逻辑蒸馏（RLD）将原始文本转换为显式的实体-关系三元组。这些关系三元组作为简洁且结构化的提示，用于最终答案预测。在OK-VQA和A-OKVQA基准上的广泛实验表明，SCoRe持续优于最先进的方法。

## Abstract
Knowledge-based Visual Question Answering aims to answer questions about an image by integrating external knowledge with visual and textual information. Recent approaches often rely on in-context learning to prompt Large Language Models (LLMs) with multimodal context in a zero-shot or few-shot manner. However, we observe that directly concatenating heterogeneous visual descriptions and retrieved knowledge into long, unstructured prompts often degrades reasoning performance, due to both excessive irrelevant context and the lack of explicit relational structure. In this paper, we propose an LLM-based Structured Context Reasoning (SCoRe) framework that infers both explicit and implicit relationships for prediction. SCoRe consists of three stages: Context Acquisition, which generates diverse visual notes and retrieves explicit knowledge via an efficient two-stage multimodal retrieval strategy; Context Selection, which filters relevant visual, explicit, and implicit knowledge using LLM-guided selection; and Context Compression, which performs Relational Logic Distillation (RLD) to transform raw text into explicit entity-relation triplets. These relational triplets serve as a concise and structured prompt for final answer prediction. Extensive experiments on the OK-VQA and A-OKVQA benchmarks demonstrate that SCoRe consistently outperforms state-of-the-art methods.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：知识增强的视觉问答（KB-VQA）要求模型结合图像信息、文本信息与外部世界知识进行推理。与常规VQA相比，KB-VQA通常涉及隐含概念和复杂多步推理，如何有效组织异构信息对准确预测至关重要。
- **核心问题**：现有的基于LLM的方法（如PICa、Img2LLM等）普遍采用零样本或少样本的上下文学习方式，将图像描述、检索知识和任务指令直接拼接为一个**非结构化长提示**。这种范式存在两个根本性缺陷：
  - **冗余信息过多**：提示中包含大量无关或弱相关的内容，分散模型对关键证据的注意力；
  - **缺乏显式关系结构**：非结构化上下文无法显式表示实体间的依赖关系，迫使LLM在推理过程中隐式推断复杂逻辑关系，而KB-VQA的答案往往依赖于对"关系"而非孤立事实的理解。
- **研究含义**：作者提出，关键在于**上下文的结构化**而非上下文的"数量"。将异构多模态信息转化为紧凑的关系表示，能够有效提升LLM在知识密集型推理任务上的表现。

## 2. 方法论

### 核心思想
提出**结构化上下文推理框架（SCoRe）**，通过三阶段流水线将原始的异构多模态输入渐进式地转化为结构化的实体-关系三元组表示，供LLM进行最终推理。

### 三大阶段

**（1）上下文获取（Context Acquisition）**
- **视觉证据**：通过三条并行的视角表征图像——目标级属性（VinVL检测器）、图像描述（问题引导式captioning）、OCR文本（Google OCR API），形成相互补充的视觉笔记集合。
- **显式知识检索**：采用**双阶段渐进式多模态检索策略**（以Google Search语料/维基百科为知识库）：
  - **第一阶段——标题级粗检索**：将图像视觉特征通过映射层投影到文本特征空间，与问题文本特征拼接形成跨模态查询向量Q，基于后期交互（late interaction）机制计算与候选标题的相关性得分，筛选top-k1个标题；
  - **第二阶段——段落级细检索**：在由top-k1标题对应的段落子集构成的候选池中，复用相同相关性度量，精确检索top-k2个知识段落。该方法将检索范围压缩数十至数百倍，同时保持高召回。

**（2）上下文选择（Context Selection）**
- 利用LLM分别对视觉笔记、显式知识段落进行筛选，去除冗余信息，保留与问题相关的视觉知识（VK）和显式知识（EK）；
- 同时结合图像描述与问题，从LLM内部知识中引导出与视觉内容对齐的**隐式知识（IK）**。

**（3）上下文压缩（Context Compression）——关系逻辑蒸馏（RLD）**
- **实体提取**：以检测目标初始化实体集，结合LLM分别从显式知识（VK+EK）中提取显式实体、从隐式知识（IK）中提取隐式实体；
- **关系提取**：在实体对之间构建显式关系三元组ER（基于显式知识）和隐式关系三元组IR（基于隐式知识），合并为初始关系集；
- **关系精炼**：从图像描述和问题中提取关键实体列表，过滤掉与关键实体无直接或间接关联（通过一条或多条关系可达）的三元组，保留最终关系集Ri。

**最终预测**：将结构化关系三元组集Ri与问题Qi共同输入QA模型（Mistral-7B/Gemma-7B）预测答案，使模型聚焦于实体间依赖推理而非原始信息的组织。
