## 摘要
持续学习在很大程度上以模型为中心，将模型参数视为随顺序经验而变化的状态。现代代理还可以通过提示、记忆、工具、技能和路由规则的组合（harness）进行适应。由于这些内容共同塑造后续执行，即使模型被冻结，组合的更新也可能破坏先前可靠的行为。这引发了一个新问题：代理如何在保留先前获得行为的同时，持续改进其模型外的状态？我们提出了组合持续学习（HCL），这是一种新的持续学习范式，其中组合围绕冻结的基础模型演化，并将由此产生的先前行为损失定义为组合级遗忘。我们用四个面向执行的组件实例化HCL：任务接口、经验记忆、能力映射和自适应路由器。我们进一步引入了受保护的组合演化，将更新生成与状态提交分离。持续优化器从执行后反馈中提出候选组合，持续评估器仅在检查当前改进、历史保持和有效性后才提交由此产生的候选组合。在文本推理、多模态感知和开放世界交互上的实验证明了能力积累和故障恢复，在多种设置中相对增益超过相应基线的10%。组件消融评估了每个组合组件的贡献，而受控保留扫描揭示了可测量的组合级遗忘，并表明稳定性-可塑性权衡可以显式调整。

## Abstract
Continual learning has largely been model-centric, treating model parameters as the state that changes with sequential experience. Modern agents can also adapt through a harness of prompts, memories, tools, skills, and routing rules. Because these contents jointly shape later execution, a harness update can disrupt previously reliable behavior even when the model is frozen. This raises a new question: how can an agent continually improve its state outside the model while retaining behavior acquired earlier? We formulate Harness Continual Learning (HCL), a new continual learning paradigm in which the harness evolves around a frozen foundation model, and define the resulting loss of earlier behavior as harness-level forgetting. We instantiate HCL with four execution-facing components: the Task Interface, Experience Memory, Capability Map, and Adaptive Router. We further introduce guarded harness evolution to separate update generation from state commitment. A Continual Optimizer proposes candidate harnesses from post-execution feedback, and a Continual Evaluator commits the resulting candidate harness only after checking current improvement, historical retention, and validity. Experiments on textual reasoning, multimodal perception, and open-world interaction demonstrate capability accumulation and failure recovery, with relative gains exceeding 10% over corresponding baselines in multiple settings. Component ablations assess the contribution of each harness component, while controlled retention sweeps reveal measurable harness-level forgetting and show that the stability--plasticity trade-off can be explicitly adjusted.

### 1. 核心问题与整体含义

- **研究动机**：传统的持续学习是**以模型为中心**（model-centric）的，将模型参数视为随顺序经验变化的状态。然而，现代 Agent 系统还可以通过外部 **harness**（提示词、记忆、工具、技能、路由规则等）进行适应。这些内容在模型冻结的情况下仍可随交互累积和演化，共同塑造后续行为。
- **核心问题**：harness 更新可能破坏早期已可靠的行为（例如一个记忆更新可能改变旧查询检索到的证据，一个技能修订可能改变工具调用方式），即使基础模型完全冻结也会出现“遗忘”。现有持续学习框架未考虑这一问题，需要新的范式来管理 harness 演化中的遗忘。
- **论文贡献**：提出 **Harness Continual Learning（HCL）** 新范式，将持续学习的研究对象从模型参数**扩展到模型外部、围绕冻结基础模型演化的 harness 状态**，并显式定义了 **harness 级遗忘（harness-level forgetting）**——即 harness 更新导致的早期行为退化，将经典稳定性–可塑性问题从模型状态延伸至 harness 状态。

### 2. 方法论

**核心思想**：HCL 将可变的 harness 视为统一的学习状态，采用 **“提案–评估–提交”** 的防护式演化（guarded harness evolution）机制，使保留（retention）成为 harness 演化的显式条件。

**（1）HCL 的 harness 状态由四个联合版本化的组件构成：**

- **Task Interface（任务接口，I）**：将原始交互 $u_n$ 转化为结构化表示 $i_n = (x_n, g_n, k_n)$，分别包含输入、目标与约束。可更新的内容包括提示词、任务模板、解析规则。
- **Experience Memory（经验记忆，M）**：分为 Raw Memory（原始交互记录 $M^{raw}_n$）和 Abstract Memory（LLM 总结的可复用指导 $M^{abs}_n$），前者保留具体经验用于复盘，后者提炼迁移性知识。
- **Capability Map（能力映射，C）**：包含外部能力 $C^{outer}_n$（API、工具等）和内部技能 $C^{inner}_n$（从 Abstract Memory 中进一步抽象出的可调用技能），允许技能库随经验扩展。
- **Adaptive Router（自适应路由器，R）**：基于结构化输入，从记忆与能力中选择相关内容并组装执行上下文 $z_n = R_n(i_n, M_n, C_n)$。

**（2）防护式 har ness 演化（核心机制）**：

- **Continual Optimizer（持续优化器）**：利用冻结的 $F_\theta$，基于部署中的 harness 和交互反馈 $e_n = (u_n, i_n, z_n, y_n, f_n)$ 生成候选 harness $\tilde{H}_{n+1} = O_{F_\theta}(H_n, e_n)$。候选生成与部署状态隔离，需经评估才可提交。
- **Continual Evaluator（持续评估器）** 对候选进行三重检查：
  - **当前改进**：$\Delta_n = P(\tilde{H}_{n+1}, V_n) - P(H_n, V_n) \geq \delta_n$
  - **历史保留**：$D_n = \sum_{a \in A_n} \mathbb{1}[q(H_n,a)=1 \land q(\tilde{H}_{n+1},a)=0] \leq B_n$，即候选使已解决的历史锚点（anchor）转向失败的数量不能超过容差
  - **有效性**：候选必须通过语法、输出格式、工具调用合法性等检查（$\forall \ell, v_{n,\ell}=1$）
- **提交决策**：$G_n^{(k)} = \mathbb{1}[(\Delta_n^{(k)} \geq \delta_n) \land (D_n^{(k)} \leq B_n) \land (\forall \ell, v_{n,\ell}=1)]$。通过硬门控的候选按综合评分排序，只有最高分者被提交为 $H_{n+1}$；无候选通过则保持 $H_n$ 不变。

**关键设计**：$B_n$ 作为历史损失容差，可视作稳定性–可塑性权衡的调节旋钮（$B_n=0$ 为 Stability-HCL 全保留配置，$B_n=\infty$ 为 Plasticity-HCL 灵活配置）。

### 6. 主要结论与发现

- **HCL 能有效累积能力并恢复失败**：ALFWorld 中 Stability-HCL 达到 61.74%、Plasticity-HCL 达到 62.98% 最终平均成功率，优于所有基线（Static 47.12%、RAG 55.56%、MemP 53.15%、MemRL 51.51%）；Minecraft 中 HCL 完成全部 50 个任务（Static 停在 15 个），且使用更少的执行动作（83 vs 88 / 91），执行效率更高。
- **harness 级遗忘真实存在且可测量**：受控保留扫描显示 $b$ 值从 0 增至 ∞ 时，平均遗忘从 0.39 升至 3.45，证实 harness 更新确实会破坏早期行为。
- **稳定性–可塑性权衡可被显式控制**：$B_n$ 是有效调节旋钮——更严格的保留约束抑制遗忘，但过度灵活（$b=\infty$）不一定带来最优最终表现（$b=1$ 时最终平均最高为 63.46%，高于 $b=\infty$ 的 60.13%），说明无约束的局部优越更新可能损害后续演化轨迹。
- **四个 harness 组件共同贡献**：消融显示移除任一组件更新均使最终平均下降，其中经验记忆和任务接口的贡献最大；记忆更新同时影响能力获取和保留。

### 7. 优点

- **概念创新**：率先将持续学习的研究对象从模型内部扩展到模型外部的 harness 整体，提出了系统性的新范式，回应了 Agent 时代持续适应的真实需求。
- **机制设计清晰**：“提案–评估–提交”分离，将保留从隐含目标变为显式提交条件，方法在定义上即具有防遗忘机制，而非事后补救。
- **类比贯通**：将模型中心 CL 的回放、表征、架构、优化、正则化等原理映射到 harness 组件，形成统一框架，理论优雅。
